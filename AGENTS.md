# Notes for AI agents

Read [CLAUDE.md](CLAUDE.md). It covers how to release Kroma Studio and when the website and docs must be updated:

- **Patch releases** (0.1.4 → 0.1.5) only need the release and a site republish.
- **Minor or major releases** (0.1.x → 0.2.0) need a new docs version and a review of every patch since the last minor, carried into the docs, changelog, site text and READMEs.
