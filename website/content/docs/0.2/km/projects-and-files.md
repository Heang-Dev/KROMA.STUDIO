ទំព័រនេះពន្យល់ពីរបៀបដែល Kroma រក្សាការងាររបស់អ្នក៖ ឯកសារគម្រោង ការរក្សាទុកស្វ័យប្រវត្តិ វីនដូបន្ថែម និងទីតាំងឯកសារនីមួយៗនៅលើកុំព្យូទ័ររបស់អ្នក។

## ឯកសារគម្រោង

គម្រោង Kroma មួយ គឺជាឯកសារតែមួយដែលបញ្ចប់ដោយ **.kroma**។ វាជាឯកសារអត្ថបទតូចមួយ (ក្នុងទម្រង់ហៅថា JSON) ដែលផ្ទុកការកែសម្រួលរបស់អ្នក៖

- ឈ្មោះគម្រោង រាងស៊ុម (16:9, 9:16 ឬ 1:1) និងរបៀបដែលវីដេអូដាក់ក្នុងស៊ុម
- បញ្ជីវីដេអូដែលអ្នកបានបន្ថែម និងទីតាំងនៃវីដេអូនីមួយៗនៅលើកុំព្យូទ័ររបស់អ្នក
- ឃ្លីបនៅលើ timeline (ផ្នែកណាខ្លះនៃវីដេអូណា)
- បន្ទាត់អក្សររត់នីមួយៗ៖ ពេលវេលា អត្ថបទដើម ការបកប្រែ និងអ្នកណាជាអ្នកនិយាយ
- រចនាប័ទ្មអក្សររត់ រួមទាំងពុម្ពអក្សរ និងចលនា
- កំណត់ចំណាំរបស់អ្នកសម្រាប់អ្នកបកប្រែ
- ការកំណត់សំឡេងបញ្ចូល៖ សំឡេង តួអង្គ ល្បឿន កម្រិតសំឡេង និងកន្លែងរក្សាទុកបន្ទាត់សំឡេងនីមួយៗ
- វត្ថុនៅលើវីដេអូ (ប្រអប់ព្រិល រូបភាព អត្ថបទ)
- ភាសាបកប្រែ
- ការបង្ហោះលើបណ្តាញសង្គមដែលបានសរសេរសម្រាប់វីដេអូ និងកន្លែងដែលអ្នកបានបង្ហោះវា
- ការកំណត់គម្រប និងវីដេអូនាំចេញតាមទម្រង់នីមួយៗ (ដើម្បីឱ្យ Kroma ដឹងថាមួយណានៅតែត្រូវនឹងគម្រោង)

**អ្វីដែលវាមិនផ្ទុក៖** វីដេអូ ការថតសំឡេង និងរូបភាពខ្លួនឯង។ គម្រោងគ្រាន់តែចងចាំថាពួកវា *នៅឯណា* ប៉ុណ្ណោះ។ ទុកឯកសារទាំងនោះនៅកន្លែងដើម បើមិនដូច្នោះទេ គម្រោងរកវាមិនឃើញ។ មើល [ផ្លាស់គម្រោងទៅកុំព្យូទ័រផ្សេង](#ផ្លាស់គម្រោងទៅកុំព្យូទ័រផ្សេង)។

## ការរក្សាទុក

| ប៊ូតុង ឬគ្រាប់ចុច | អ្វីដែលវាធ្វើ |
|---|---|
| **Save project** (⌘S / Ctrl+S) | រក្សាទុកទៅក្នុងឯកសាររបស់គម្រោង។ លើកដំបូង វាសួររកឈ្មោះ និងកន្លែង។ |
| ⇧⌘S / Ctrl+Shift+S | រក្សាទុកជាឯកសារថ្មី។ សួររកឈ្មោះ និងកន្លែងរាល់ពេល។ |
| **Open project** (⌘O / Ctrl+O) | បើកឯកសារ `.kroma`។ |
| **New project** (⌘N / Ctrl+N) | ចាប់ផ្តើមគម្រោងទទេមួយឈ្មោះ **Untitled**។ |

ប៊ូតុង **Save project**, **Open project** និង **New project** នៅខាងស្តាំខាងលើនៃវីនដូ។

ប្រអប់រក្សាទុក និងបើក ចាប់ផ្តើមនៅក្នុង[ថតបណ្ណាល័យ Kroma Studio](#ទីតាំងឯកសារ) របស់អ្នក ហើយឈ្មោះឯកសារចាប់ផ្តើមដោយឈ្មោះគម្រោង។ ពេលអ្នកបន្ថែមវីដេអូដំបូង Kroma ដាក់ឈ្មោះគម្រោងតាមវីដេអូនោះ។ ចុចលើឈ្មោះនៅខាងលើ ដើម្បីប្តូរវា។

ចំណុចតូចមួយនៅក្បែរឈ្មោះគម្រោង មានន័យថា **Unsaved changes**៖ គម្រោងបានផ្លាស់ប្តូរ តាំងពីពេលអ្នករក្សាទុកវាទៅក្នុងឯកសារលើកចុងក្រោយ។

បើអ្នកចាប់ផ្តើមគម្រោងថ្មី ខណៈគម្រោងបច្ចុប្បន្នមិនដែលបានរក្សាទុកទៅក្នុងឯកសារ Kroma សួរអ្នកជាមុនសិន៖ *"Start a new project? The current one isn't saved to a file (it stays in autosave until you start another)."*

## ការរក្សាទុកស្វ័យប្រវត្តិ និងការស្តារ

អ្នកមិនចាំបាច់រក្សាទុក ដើម្បីការពារការងាររបស់អ្នកទេ។ ប្រហែលមួយវិនាទីកន្លះ បន្ទាប់ពីការផ្លាស់ប្តូរនីមួយៗ Kroma សរសេរគម្រោងដែលកំពុងបើកទៅក្នុងឯកសាររក្សាទុកស្វ័យប្រវត្តិ (autosave)។

ពេលអ្នកបើក Kroma ម្តងទៀត វាបើកគម្រោងចុងក្រោយរបស់អ្នកមកវិញ ហើយបង្ហាញ **Reopened your last project.** នេះក៏ជួយពេលកម្មវិធីគាំង ដាច់ភ្លើង ឬបិទ Kroma ដោយមិនបានរក្សាទុកផងដែរ។ បើគម្រោងបានរក្សាទុកទៅក្នុងឯកសារ វាបើកមកវិញភ្ជាប់នឹងឯកសារនោះ។ បើមិនទាន់ទេ វាបើកមកវិញជាមួយចំណុចមិនទាន់រក្សាទុក ដើម្បីរំលឹកអ្នកឱ្យរក្សាទុកវា។

Autosave រក្សាគម្រោងមួយក្នុងមួយវីនដូ។ ការចាប់ផ្តើមគម្រោងថ្មីជំនួសវា។ ដូច្នេះសម្រាប់ការងារដែលអ្នកចង់រក្សា សូមប្រើ **Save project** ផងដែរ។

ប្រវត្តិ Undo (១០០ ជំហាន) មិនត្រូវបានរក្សាទុកទេ៖ បន្ទាប់ពី Kroma បើកឡើងវិញ អ្នកមិនអាច undo ការផ្លាស់ប្តូរពីមុននោះបានទេ។

## វីនដូច្រើន

អ្នកអាចធ្វើការលើគម្រោងពីរក្នុងពេលតែមួយ ម្នាក់ៗក្នុងវីនដូរបស់ខ្លួន។

- **File → New Window** (⇧⌘N / Ctrl+Shift+N)
- Mac៖ ចុចកណ្ដុរស្តាំលើ Kroma ក្នុង Dock → **New Window**
- Windows៖ ចុចកណ្ដុរស្តាំលើ Kroma នៅលើ taskbar → **New Window**

វីនដូនីមួយៗមានគម្រោងផ្ទាល់ខ្លួន និងកន្លែង autosave ផ្ទាល់ខ្លួន៖

| វីនដូ | Autosave |
|---|---|
| វីនដូទីមួយ | `autosave.json`។ បើកមកវិញពេល Kroma ចាប់ផ្តើម។ |
| វីនដូបន្ថែមនីមួយៗ | `autosave-2.json`, `autosave-3.json` …។ ត្រូវបានលុបពេលអ្នកបិទវីនដូនោះ។ |

ដោយសារ autosave របស់វីនដូបន្ថែមបាត់ទៅវិញ Kroma សួរមុនពេលអ្នកបិទវីនដូបន្ថែម ដែលគម្រោងរបស់វាមិនទាន់រក្សាទុកទៅក្នុងឯកសារ៖ **Close this window?** ជ្រើស **Cancel** រក្សាទុកគម្រោង រួចបិទវា។

## Kroma តែមួយក្នុងពេលតែមួយ

Kroma ដំណើរការតែម្តងប៉ុណ្ណោះ។ បើអ្នកបើកវាម្តងទៀតខណៈវាកំពុងដំណើរការ (ពី Dock, ម៉ឺនុយ Start ឬផ្លូវកាត់លើ desktop) វានាំវីនដូដែលកំពុងបើកមកខាងមុខ ជំនួសឱ្យការបើកច្បាប់ទីពីរ។ នេះការពារមិនឱ្យច្បាប់ពីរសរសេរឯកសារ autosave តែមួយ។ **New Window** លើ taskbar បើកវីនដូថ្មីក្នុង Kroma ដែលកំពុងដំណើរការ។

លើ Mac ការបិទវីនដូទាំងអស់ទុក Kroma ឱ្យនៅដំណើរការ។ ចុចរូបតំណាងរបស់វាក្នុង Dock ដើម្បីបើកវីនដូម្តងទៀត។ លើ Windows និង Linux ការបិទវីនដូចុងក្រោយ គឺបិទ Kroma តែម្តង។

## ទីតាំងឯកសារ

Kroma ប្រើថតពីរ។

### ថតការកំណត់

ការកំណត់ key និង autosave របស់អ្នក។

| ប្រព័ន្ធ | ថត |
|---|---|
| macOS | `~/Library/Application Support/Kroma Studio` |
| Windows | `%APPDATA%\Kroma Studio` |
| Linux | `~/.config/Kroma Studio` |

`~` មានន័យថាថតផ្ទះ (home) របស់អ្នក។ លើ Windows បិទភ្ជាប់ `%APPDATA%\Kroma Studio` ទៅក្នុងរបារអាសយដ្ឋានរបស់ File Explorer ដើម្បីបើកវា។

| ឯកសារ | វាជាអ្វី |
|---|---|
| `settings.json` | អ្វីៗទាំងអស់ក្នុង [Settings](settings)។ API key ត្រូវបានអ៊ិនគ្រីប (មើលខាងក្រោម)។ |
| `autosave.json`, `autosave-2.json` … | គម្រោងដែលបានរក្សាទុកស្វ័យប្រវត្តិរបស់វីនដូនីមួយៗ |
| `last-export-error.log` | ព័ត៌មានលម្អិតនៃការនាំចេញចុងក្រោយដែលបរាជ័យ (មើល [ដោះស្រាយបញ្ហា](troubleshooting#ការនាំចេញបរាជ័យ)) |
| `updates` | កំណែថ្មីដែលបានទាញយក លើ macOS និង Linux `.deb` |
| `my-styles.json` | រូបរាងអក្សររត់ដែលអ្នកបានរក្សាទុក (**Style → Save as my style**) |
| `voice-engine` | ម៉ាស៊ីនសំឡេងរបស់ Kroma ពេលអ្នកដំឡើងវា (ប្រហែល 2 GB) |

ប្រវត្តិការជូនដំណឹង និងទំហំផ្ទាំង ក៏ត្រូវបានរក្សាទុកក្នុងកន្លែងផ្ទុកផ្ទាល់ខ្លួនរបស់ Kroma ក្នុងថតនេះដែរ។

### ថតបណ្ណាល័យ Kroma Studio

វីដេអូរបស់អ្នក និងអ្វីៗដែល Kroma បង្កើតចេញពីវា។ វានៅក្នុងថត Movies លើ Mac និងថត Videos លើ Windows និង Linux៖

| ប្រព័ន្ធ | ថត |
|---|---|
| macOS | `~/Movies/Kroma Studio` |
| Windows | `C:\Users\<you>\Videos\Kroma Studio` |
| Linux | `~/Videos/Kroma Studio` |

## key របស់អ្នកនៅលើថាស

API key ត្រូវបានអ៊ិនគ្រីបដោយ keychain នៃប្រព័ន្ធរបស់អ្នក មុនពេលសរសេរទៅក្នុង `settings.json` ហើយវាដំណើរការតែលើកុំព្យូទ័រដែលបានរក្សាទុកវាប៉ុណ្ណោះ។ លើប្រព័ន្ធ Linux ខ្លះ មិនមាន keychain ទេ៖ នៅទីនោះ key ត្រូវបានរក្សាទុកជាអត្ថបទធម្មតា ដូច្នេះសូមរក្សាឯកសារនោះជាឯកជន។

## ផ្លាស់គម្រោងទៅកុំព្យូទ័រផ្សេង

ឯកសារ `.kroma` គ្រាន់តែចង្អុលទៅឯកសាររបស់អ្នក តាមទីតាំងពេញរបស់វា ឧទាហរណ៍ `/Users/dara/Movies/Kroma Studio/downloads/…`។ Kroma មិនមានប៊ូតុងសម្រាប់ស្វែងរកឯកសារដែលបានផ្លាស់ទីវិញទេ។ ដើម្បីផ្លាស់គម្រោង៖

1. ចម្លងឯកសារ `.kroma` **និង**ថតបណ្ណាល័យ Kroma Studio (ជាមួយថត `downloads`, `voice-cache`, `voices` និង `cache` របស់វា)។ ចម្លងវីដេអូ ឬរូបភាពណាដែលអ្នកបានបន្ថែមពីកន្លែងផ្សេងផងដែរ។
2. ដាក់វានៅ**កន្លែងដដែលបេះបិទ**លើកុំព្យូទ័រថ្មី។ វិធីនេះដំណើរការល្អបំផុតរវាងកុំព្យូទ័រពីរប្រភេទដូចគ្នា (Mac ទៅ Mac, Windows ទៅ Windows) ដែលមានឈ្មោះអ្នកប្រើដូចគ្នា។
3. បើកគម្រោងដោយ **Open project**។

បើថតលើកុំព្យូទ័រថ្មីខុសគ្នា វិធីងាយបំផុតគឺចាប់ផ្តើមគម្រោងថ្មីនៅទីនោះ ហើយយកអក្សររត់របស់អ្នកទៅជាមួយ៖

1. នៅលើកុំព្យូទ័រចាស់ បើកផ្ទាំង **Post** ហើយនៅក្រោម **Subtitle files** រក្សាទុកឯកសារ `.srt` ដែលបានបកប្រែ (សម្រាប់ខ្មែរ គឺ **Khmer .srt**)។
2. នៅលើកុំព្យូទ័រថ្មី បន្ថែមវីដេអូម្តងទៀត រួចប្រើ **Import an .srt file** នៅខាងលើបញ្ជីអក្សររត់។

ឯកសារ `.srt` មួយផ្ទុកតែភាសាមួយ ដូច្នេះវិធីនេះនាំមកវិញតែការបកប្រែ មិនមែនបន្ទាត់ដើម អ្នកនិយាយ ឬសំឡេងបញ្ចូលទេ។

key មិនផ្លាស់ទីតាមទេ៖ វាជាប់សោនឹងកុំព្យូទ័រដែលបានរក្សាទុកវា។ សូមបន្ថែមវាម្តងទៀតក្នុង [Settings](settings) លើកុំព្យូទ័រថ្មី។
