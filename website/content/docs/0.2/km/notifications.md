ការងារវែងៗ ដូចជាការទាញយក ការបកប្រែ ការដាក់សំឡេង ការនាំចេញ ឬ batch ទាំងមូល អាចចំណាយពេលច្រើននាទី។ Kroma ប្រាប់អ្នកពេលការងារនីមួយៗរួច ឬបរាជ័យ ដូច្នេះអ្នកអាចទៅធ្វើការងារផ្សេង ឬប្រើកម្មវិធីផ្សេងក្នុងពេលរង់ចាំ។

## កណ្តឹង

កណ្តឹងនៅរបារចំណងជើង បន្ទាប់ពី **New**, **Open** និង **Save** រក្សាទុកអ្វីៗទាំងអស់ដែលរួច ឬបរាជ័យ៖ ការទាញយក អក្សររត់ ការបកប្រែ ការដាក់សំឡេង ការនាំចេញ ការបង្ហោះ រឿង ម៉ាស៊ីនសំឡេង និងការធ្វើបច្ចុប្បន្នភាព។ លេខនៅលើវារាប់ការជូនដំណឹងថ្មី។

ចុចលើវាដើម្បីបើកបញ្ជី ថ្មីបំផុតនៅខាងលើ។ ការជូនដំណឹងនីមួយៗមាន៖

- សញ្ញាធីកបៃតង (រួច) សញ្ញាខ្វែងក្រហម (បរាជ័យ) ឬសញ្ញាព័ត៌មាន
- ចំណងជើង ហើយនៅខាងក្រោម មូលហេតុ ឬព័ត៌មានលម្អិត (អ្នកអាចជ្រើស និងចម្លងវាបាន)
- ពេលដែលវាកើតឡើង
- ប៊ូតុងមួយ ពេលមានអ្វីត្រូវធ្វើបន្ត៖ **Retry**, **Open project**, **Show in Finder** (**Show in folder** លើ Windows និង Linux), **Open Downloads**, **Open Batch**, **Open Story**, **Open Settings** ឬ **Restart** សម្រាប់កំណែថ្មីដែលរួចរាល់

**Mark all read** លុបលេខចោល ហើយ **Clear** សម្អាតបញ្ជីទាំងមូល។ ពេលគ្មានអ្វីសោះ វាសរសេរថា *You're all caught up*។

កណ្តឹងរក្សាការជូនដំណឹង 100 ចុងក្រោយ ហើយវានៅតែមានក្រោយពេលបើក Kroma ឡើងវិញ។ ប៊ូតុង **Retry** ដំណើរការតែរហូតដល់ Kroma បិទបើកវិញប៉ុណ្ណោះ។ ក្រោយនោះ ចាប់ផ្តើមការងារម្តងទៀតពីផ្ទាំងរបស់វា។

## បីរបៀបដែល Kroma ប្រាប់អ្នក

| នៅឯណា | ពេលណា |
|---|---|
| **សារក្នុង Kroma** | នៅជ្រុងខាងស្តាំខាងក្រោមនៃបង្អួច ពេលការងាររួច ឬបរាជ័យ។ |
| **ការជូនដំណឹងរបស់ប្រព័ន្ធ** | ការជូនដំណឹងរបស់កុំព្យូទ័រអ្នកផ្ទាល់ ពេលអ្នកកំពុងប្រើកម្មវិធីផ្សេង។ បើបរាជ័យ វាបង្ហាញទោះអ្នកកំពុងនៅក្នុង Kroma ក៏ដោយ។ |
| **កណ្តឹង** | ជានិច្ច។ អ្វីៗទាំងអស់ចូលកណ្តឹង មិនថាការកំណត់របស់អ្នកយ៉ាងណាទេ។ |

ការងារវែងៗមិនរំខានអ្នកពេកទេ៖ Download Center និង Batch ប្រាប់អំពីវីដេអូនីមួយៗ រួចផ្ញើសេចក្តីសង្ខេបតែមួយនៅចុងបញ្ចប់ (ឧទាហរណ៍ *Batch finished: 5 processed · 1 failed*)។

## Settings → Notifications

បើក **Settings → Notifications** ដើម្បីជ្រើសអ្វីដែលអ្នកចង់ដឹង។

| ជម្រើស | លំនាំដើម | ធ្វើអ្វី |
|---|---|---|
| **Notify me when Kroma is in the background** | បើក | ការជូនដំណឹងរបស់ប្រព័ន្ធ។ បើបរាជ័យ វាបង្ហាញទោះអ្នកនៅក្នុង Kroma ក៏ដោយ។ |
| **Play a sound** | បើក | បន្លឺសំឡេងពេលការងាររួច ឬបរាជ័យ ទាំងក្នុង Kroma និងក្នុងការជូនដំណឹងរបស់ប្រព័ន្ធ។ |
| **When work is done** | Glass | សំឡេងសម្រាប់ការងារដែលរួច។ លើ Mac ជ្រើសពីសំឡេងរបស់ Mac ផ្ទាល់ ហើយចុច **Play** ដើម្បីស្តាប់។ |
| **When something fails** | Basso | សំឡេងសម្រាប់ការបរាជ័យ។ |
| **Only when something fails** | បិទ | ការងារដែលរួចបង្ហាញតែក្នុងកណ្តឹងប៉ុណ្ណោះ គ្មានការជូនដំណឹងរបស់ប្រព័ន្ធ។ |
| **Send a test notification** → **Send test** | — | បង្ហាញការជូនដំណឹងរបស់ប្រព័ន្ធភ្លាមៗ ហើយបន្ថែមវាទៅកណ្តឹង។ |

លើ Windows និង Linux ការជូនដំណឹងរបស់ប្រព័ន្ធប្រើសំឡេងរបស់ប្រព័ន្ធផ្ទាល់ ហើយសារក្នុង Kroma បន្លឺសំឡេងកណ្តឹងខ្លីមួយ។

### អ្វីដែលត្រូវជូនដំណឹង

មានកុងតាក់មួយសម្រាប់ការងារនីមួយៗ៖ **Downloads**, **Subtitles & translation**, **Voices & stories**, **Export & posting** និង **Updates**។ ពេលបិទ ការងារប្រភេទនោះគ្មានការជូនដំណឹងរបស់ប្រព័ន្ធ និងគ្មានសារក្នុង Kroma ពេលវាជោគជ័យទេ។ ការបរាជ័យនៅតែបង្ហាញ ហើយអ្វីៗទាំងអស់នៅតែរក្សាទុកក្នុងកណ្តឹង។

### ប្រវត្តិ

**Notification history** បង្ហាញចំនួនការជូនដំណឹងក្នុងកណ្តឹង។ **Clear history** សម្អាតវា។

## មិនឃើញការជូនដំណឹង?

កុំព្យូទ័ររបស់អ្នកជាអ្នកសម្រេចថា Kroma អាចបង្ហាញការជូនដំណឹងបានឬទេ ហើយមានសំឡេងឬអត់។ បើ **Send test** មិនបង្ហាញអ្វីនៅក្រៅ Kroma៖

1. បើក **Settings → Notifications → Not seeing them?** ហើយចុច **Open**។ វាបើកការកំណត់ការជូនដំណឹងរបស់ប្រព័ន្ធ។
2. លើ Mac៖ **System Settings → Notifications → Kroma Studio** បើក **Allow notifications** និង **Play sound for notifications**។ លើ Windows និង Linux អនុញ្ញាតការជូនដំណឹងពី Kroma Studio។
3. ចុច **Send test** ម្តងទៀត។

ពិនិត្យផងដែរថា Focus ឬ Do Not Disturb មិនបានបើក ហើយ **Notify me when Kroma is in the background** កំពុងបើក។
