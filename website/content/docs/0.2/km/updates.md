Kroma ធ្វើបច្ចុប្បន្នភាពដោយខ្លួនឯង។ កំណែថ្មីទាញយកនៅពីក្រោយ ពេលអ្នកកំពុងធ្វើការ ហើយអ្នកជ្រើសពេលបើកឡើងវិញ។ គម្រោងរបស់អ្នកត្រូវបានរក្សាទុក ហើយបើកមកវិញក្រោយពេលបើកឡើងវិញ។

## របៀបដែលវាដំណើរការ

1. **Kroma ពិនិត្យរកកំណែថ្មី។** ការពិនិត្យលើកដំបូងកើតឡើងប្រហែល ៨ វិនាទីក្រោយ Kroma ចាប់ផ្តើម បន្ទាប់មករៀងរាល់ ៤ ម៉ោងម្តង ពេលវាកំពុងបើក។ កំណែថ្មីមកពី [GitHub Releases](https://github.com/Heang-Dev/kroma/releases)។
2. **វាទាញយកនៅពីក្រោយ។** ប្រអប់មួយលេចឡើងនៅជ្រុងខាងក្រោមស្តាំ៖ **Downloading Kroma 0.2.1**, "It downloads in the background and picks up where it stopped if the connection drops. Keep working." ជាមួយរបារវឌ្ឍនភាព ល្បឿន និងពេលនៅសល់ (ដូចជា *2.4 MB/s · 35 s left*)។
3. **វារួចរាល់។** ប្រអប់ប្តូរទៅជា **Kroma 0.2.1 is ready**, "Restart to finish updating. Your project is saved and opens again." អ្នកក៏ទទួលបាន[ការជូនដំណឹង](notifications)ដែរ។ ប្រអប់មានប៊ូតុងពីរ៖
   - **Restart to update**៖ Kroma បិទ ដំឡើងកំណែថ្មី ហើយបើកឡើងវិញជាមួយគម្រោងរបស់អ្នក។
   - **Later**៖ បង្រួមប្រអប់ទុក។ អ្នកអាចបន្តធ្វើការបានយូរតាមចិត្ត។

បើ Kroma ជាកំណែចុងក្រោយស្រាប់ គ្មានអ្វីលេចឡើងទេ។

ការដាច់អ៊ីនធឺណិតមិនធ្វើឱ្យការទាញយកចាប់ផ្តើមពីដើមទេ៖ Kroma បន្តពីកន្លែងដែលវាឈប់ ហើយការទាញយកដែលនៅពាក់កណ្តាលពេលអ្នកបិទ Kroma ក៏ដូចគ្នាដែរ។

## របារស្ថានភាព

របារស្ថានភាពនៅខាងក្រោមនៃគ្រប់ទំព័រ បង្ហាញការធ្វើបច្ចុប្បន្នភាពនៅចុងខាងស្តាំរបស់វា៖

- **Check for updates** ពេលគ្មានអ្វីកំពុងកើតឡើង។ ចុចវាដើម្បីពិនិត្យភ្លាមៗ។ បើអ្នកមានកំណែចុងក្រោយ Kroma ប្រាប់ថា *Kroma is up to date (0.2.0)*។
- **Updating 45% · 35 s left** ពេលវាកំពុងទាញយក ហើយប្រអប់ត្រូវបានបង្រួមទុក។
- **Restart to update** (ពណ៌បៃតង) ពេលវារួចរាល់ ហើយអ្នកបានចុច **Later**។
- **Update to 0.2.1** ពេលការធ្វើបច្ចុប្បន្នភាពស្វ័យប្រវត្តិបិទ ហើយមានកំណែថ្មី។

ចុចលើណាមួយ ដើម្បីបង្ហាញប្រអប់មកវិញ។ ប៊ូតុងបង្រួមនៅជ្រុងខាងលើស្តាំនៃប្រអប់ (**Minimize to the status bar**) ធ្វើដូច **Later** ដែរ។

## ការកំណត់ការធ្វើបច្ចុប្បន្នភាព

បើក **Settings → About**។ ប្រអប់ **Updates** មាន៖

| ការកំណត់ | តួនាទី |
|---|---|
| **Check for updates** · **Check now** | ស្វែងរកកំណែថ្មីភ្លាមៗ។ បន្ទាត់ខាងក្រោមវាប្រាប់ថាមានអ្វីកើតឡើង ឧទាហរណ៍ "You have the latest version (0.2.0)." ឬ "Downloading Kroma 0.2.1 · 45%"។ |
| **Update automatically** | បើកជាលំនាំដើម៖ កំណែថ្មីទាញយកនៅពីក្រោយ។ បើបិទ៖ Kroma គ្រាន់តែប្រាប់ថាមានកំណែថ្មី ហើយមិនទាញយកអ្វីទេ រហូតដល់អ្នកសុំ។ |
| **What's new** · **Changelog** | បើកបញ្ជីការផ្លាស់ប្តូរនៅលើគេហទំព័រ Kroma។ |

### ពេលបិទ Update automatically

Kroma នៅតែពិនិត្យពេលចាប់ផ្តើម និងរៀងរាល់ ៤ ម៉ោង។ ពេលមានកំណែថ្មី ប្រអប់សរសេរថា **Kroma 0.2.1 is available**, "A new version of Kroma is out." ជាមួយ **Download** និង **Later**។ ចុច **Download** ដើម្បីយកវា បន្ទាប់មកប្រអប់បង្ហាញដំណើរការ និង **Restart to update** ដូចធម្មតា។

**Check now** និង **Check for updates** ក៏ធ្វើតាមការកំណត់នេះដែរ៖ ពេលវាបិទ ពួកវាគ្រាន់តែប្រាប់ថាមានកំណែថ្មី។ អ្នកជាអ្នកជ្រើសពេលទាញយក។

## របៀបដំឡើងលើប្រព័ន្ធនីមួយៗ

| ប្រព័ន្ធ | អ្វីកើតឡើងពេលចុច Restart to update |
|---|---|
| **macOS** | Kroma បានចម្លងកម្មវិធីថ្មីចេញពី `.dmg` ដែលទាញយករួចហើយ។ ពេលបើកឡើងវិញ វាប្តូរកម្មវិធីថ្មីចូលកន្លែង (ដោយរក្សាកម្មវិធីចាស់ទុក រហូតដល់ការចម្លងជោគជ័យ) ដកសញ្ញា «ទាញយកពីអ៊ីនធឺណិត» ហើយបើកវា។ អ្នកមិនចាំបាច់ប្រើពាក្យបញ្ជា `xattr` ម្តងទៀតទេ។ |
| **Windows** | កម្មវិធីដំឡើងថ្មីដំណើរការ ហើយ Kroma បើកឡើងវិញ។ |
| **Linux AppImage** | ឯកសារ AppImage ត្រូវបានជំនួសដោយឯកសារថ្មី ហើយ Kroma បើកឡើងវិញ។ |
| **Linux .deb** | ការដំឡើង `.deb` ត្រូវការពាក្យសម្ងាត់របស់អ្នក ដូច្នេះ Kroma មិនអាចធ្វើតែឯងបានទេ។ វាទាញយក `.deb` ថ្មី ហើយបើកវាក្នុងកម្មវិធីដំឡើងរបស់ប្រព័ន្ធ។ ដំឡើងវានៅទីនោះ រួចបើក Kroma ម្តងទៀត។ |

នៅលើ **Windows** និងជាមួយ **AppImage** បើអ្នកគ្រាន់តែបិទ Kroma ក្រោយពេលទាញយកការធ្វើបច្ចុប្បន្នភាពរួច វាដំឡើងពេល Kroma បិទ។ នៅលើ **Mac** កំណែថ្មីត្រូវបានដាក់ចូលកន្លែង តែពេលអ្នកចុច **Restart to update** ប៉ុណ្ណោះ។

### លើ Mac

ចាប់ពី 0.1.12 ការធ្វើបច្ចុប្បន្នភាពលើ Mac ប្រុងប្រយ័ត្នជាងមុន៖

- **ទាញយកម្តងមួយ។** ការពិនិត្យម្តងទៀតពេលកំពុងទាញយក មិនចាប់ផ្តើមទាញយកឯកសារដដែលជាលើកទីពីរទេ។
- **ការទាញយកដែលខូចត្រូវបានរកឃើញ។** Kroma ពិនិត្យឯកសារដែលទាញយក ធៀបនឹងឯកសារនៅលើ GitHub ហើយទាញយកម្តងទៀត ជំនួសឱ្យការដំឡើងច្បាប់ចម្លងដែលខូច។
- **កំណែដែលទាញយករួច នៅដដែលក្រោយបិទបើក។** បើអ្នកបិទ Kroma មុនចុច **Restart to update** លើកក្រោយការធ្វើបច្ចុប្បន្នភាពរួចរាល់ភ្លាម ដោយមិនបាច់ទាញយកម្តងទៀត។
- **បើដំឡើងមិនបាន Kroma ប្រាប់មូលហេតុ។** ពេល Mac របស់អ្នកមិនអនុញ្ញាតឱ្យ Kroma ជំនួសខ្លួនឯងក្នុង Applications នោះ Kroma បើកមកវិញលើកំណែចាស់ បង្ហាញ *The update couldn't be installed* ជាមួយមូលហេតុ ហើយបើក Kroma Studio ថ្មីក្នុង Finder ដើម្បីឱ្យអ្នកអូសវាចូល **Applications**។ អ្នកក៏អាចអនុញ្ញាត Kroma Studio ក្នុង **System Settings → Privacy & Security → App Management** រួចធ្វើបច្ចុប្បន្នភាពម្តងទៀត។
