អ្វីដែលបានផ្លាស់ប្តូរក្នុងកំណែនីមួយៗនៃស៊េរី 0.2 ពីថ្មីបំផុតទៅចាស់។

## 0.2 ដោយសង្ខេប

0.2 គឺសម្រាប់ **រឿងភាគទាំងមូល**។ ចាប់ពី 0.1 មក Kroma បានរីកចម្រើនពីការធ្វើវីដេអូម្តងមួយៗ ទៅជាឧបករណ៍សម្រាប់រឿងភាគដែលមានសែសិបភាគ៖

- **[Download Center](downloading#download-center)**៖ បិទភ្ជាប់តំណរឿងភាគ collection បញ្ជីចាក់ ឬឆានែល គូសធីកភាគដែលចង់បាន ហើយភាគនីមួយៗក្លាយជាគម្រោងមួយដែលមានលេខរៀង។ ថតភាគដែលអ្នកមានស្រាប់ ក៏នាំចូលតាមរបៀបដូចគ្នាដែរ។
- **[Batch](batch)**៖ ជ្រើសជំហានតែម្តង (អក្សររត់ ការបកប្រែ ការដាក់សំឡេង ការលាក់អក្សររត់ដើម រចនាប័ទ្ម ការនាំចេញ គម្រប អត្ថបទបង្ហោះ) ហើយគ្រប់ភាគឆ្លងកាត់ជំហានទាំងនោះម្តងមួយៗ រួចរង់ចាំក្នុង **Ready to post** ជាមួយទម្រង់ត្រឹមត្រូវសម្រាប់វេទិកានីមួយៗ។
- **[លាក់អក្សររត់ដើម](style-and-objects#លាក់អក្សររត់ដើម)**៖ Kroma រកអក្សររត់ចិនដែលដិតជាប់ក្នុងវីដេអូ ហើយធ្វើឱ្យព្រិលត្រូវតែកន្លែងនោះ។
- **[អក្សររត់មានចលនា](style-and-objects#ចលនា)**, **រចនាប័ទ្មអក្សររត់ 33**, ពុម្ពអក្សរខ្មែរសម្រាប់ចំណងជើងប្រាំពីរ ស្រមោល និងពន្លឺ ព្រមទាំង **[My styles](style-and-objects#រចនាប័ទ្មរបស់ខ្ញុំ)** សម្រាប់រូបរាងផ្ទាល់ខ្លួនរបស់អ្នក។
- **[សទ្ទានុក្រមរឿងភាគ](translation#សទ្ទានុក្រមរឿងភាគ)**៖ ការសរសេរតែមួយសម្រាប់ឈ្មោះនីមួយៗ ក្នុងគ្រប់ភាគ។
- **[គម្របភាគ](posting#គម្របភាគ)** ដែលមានលេខភាគ ទាំង 16:9 និង 9:16។
- **[ស្ទូឌីយោរឿង](story)** **[ម៉ាស៊ីនសំឡេង](voice-engine)** ផ្ទាល់របស់ Kroma ដែលមានស្រាប់ក្នុងកម្មវិធី **[ការជូនដំណឹង](notifications)** ជាមួយកណ្តឹង និងសំឡេង ម៉ឺនុយទម្លាក់ដែលស្វែងរកបាន និងការធ្វើបច្ចុប្បន្នភាពដែលទុកចិត្តបានជាងមុន។

គម្រោងពី 0.1 បើកបានក្នុង 0.2 ហើយមានរូបរាងដូចដើមទាំងស្រុង។ ការដំឡើងទៅកំណែថ្មីនេះ មិនទាមទារអ្វីពីអ្នកទេ៖ មើល [ការណែនាំអំពីការដំឡើងកំណែ](upgrade)។ កំណែ 0.1.x ដែលនាំមកដល់ទីនេះ មាននៅក្នុងឯកសារណែនាំ 0.1 (ប្រើម៉ឺនុយកំណែនៅខាងលើរបារចំហៀង) និងនៅលើ [Changelog](/changelog/)។

## របៀបដាក់លេខកំណែ

កំណែ Kroma មានលេខបី ដូចជា **0.2.0**៖

| ផ្នែក | ក្នុង 0.2.0 | អត្ថន័យ |
|---|---|---|
| ទីមួយ | 0 | Kroma នៅក្មេងនៅឡើយ។ វាក្លាយជា 1 នៅកំណែស្ថិរភាពដំបូង។ |
| ទីពីរ | 2 | ស៊េរី។ ឯកសារណែនាំនេះសម្រាប់ស៊េរី 0.2។ ស៊េរីថ្មីអាចនាំមកនូវការផ្លាស់ប្តូរធំជាង ហើយមានឯកសារណែនាំផ្ទាល់ខ្លួន។ |
| ទីបី | 0 | កំណែមួយក្នុងស៊េរី៖ ការជួសជុល និងមុខងារថ្មី។ គ្រប់កំណែ 0.2.x បើកគម្រោងពីកំណែមុនៗបាន។ |

លេខត្រូវបានប្រៀបធៀបម្តងមួយផ្នែកៗ ដូច្នេះ 0.2.10 ថ្មីជាង 0.2.9 ហើយ 0.2.0 ថ្មីជាង 0.1.13។

## កំណែណាដែលអ្នកមាន

បើក **Settings → About** (⌘, ឬ Ctrl+, រួច **About**)។ បន្ទាត់ខាងលើបង្ហាញវា ឧទាហរណ៍ **Kroma Studio 0.2.0**។ នៅក្រោម **Updates** បន្ទាត់ក្បែរ **Check for updates** ក៏ប្រាប់ផងដែរថាអ្នកមានកំណែចុងក្រោយឬនៅ។ កំណែក៏បង្ហាញនៅខាងក្រោមរបារចំហៀងរបស់ Settings ដែរ។

## ការយកកំណែថ្មី

Kroma ធ្វើបច្ចុប្បន្នភាពដោយខ្លួនឯង៖ មើល [ការធ្វើបច្ចុប្បន្នភាព](updates)។ ដើម្បីដំឡើងកំណែជាក់លាក់ណាមួយដោយដៃ មើល[ការណែនាំអំពីការដំឡើងកំណែ](upgrade)។ កំណែនីមួយៗ ជាមួយឯកសារទាញយករបស់វា ក៏មាននៅលើ [GitHub Releases](https://github.com/Heang-Dev/kroma/releases) ដែរ។
