ឯកសារយោងសម្រាប់ជម្រើសនីមួយៗក្នុង Settings៖ វាធ្វើអ្វី និងតម្លៃរបស់វាពេលអ្នកទើបដំឡើង Kroma ដំបូង (លំនាំដើម)។

## បើក Settings

- ចុច ⌘, (Mac) ឬ Ctrl+, (Windows / Linux) ឬ
- ចុច **Settings** (រូបកង់) នៅខាងក្រោមម៉ឺនុយខាងឆ្វេង។

Settings បើកពេញវីនដូ។ ទំព័រនានាត្រូវបានរាយនៅខាងឆ្វេងជាក្រុម ហើយកំណែដែលអ្នកកំពុងប្រើនៅខាងក្រោម។ **Back to app**, សញ្ញា **×** នៅខាងស្តាំខាងលើ ឬ Esc នាំអ្នកត្រឡប់ទៅកម្មវិធីកែសម្រួលវិញ។

**ការផ្លាស់ប្តូររក្សាទុកភ្លាមៗ ពេលអ្នកធ្វើ។** គ្មានប៊ូតុង Save ទេ លើកលែងតែសម្រាប់ API key។

ដើម្បីរកជម្រើសមួយឱ្យលឿន វាយក្នុង **Search settings** (⌘F / Ctrl+F)។ វាផ្គូផ្គងឈ្មោះទំព័រ និងពាក្យទូទៅ ដូចជា "cookies", "zoom" ឬ "Groq"។ ចុច Enter ដើម្បីបើកលទ្ធផលទីមួយ។

ពេលអ្នកបើក Kroma ជាលើកដំបូងបង្អស់ Settings បើកនៅទំព័រ **Translation** ឱ្យអ្នក ដើម្បីបន្ថែម key។ ក្រោយមក Kroma បើកនៅកន្លែងដែលអ្នកធ្វើការ ទោះក្រោយបិទបើកឡើងវិញ ឬក្រោយធ្វើបច្ចុប្បន្នភាពក៏ដោយ។

## របៀបដែលប្រអប់ key ដំណើរការ

ប្រអប់ API key ទាំងអស់ដំណើរការដូចគ្នា៖

- បិទភ្ជាប់ key រួចចុច **Save**។ ប្រអប់នោះបង្ហាញស្លាក **Saved**។ Kroma មិនបង្ហាញ key នោះម្តងទៀតទេ។
- **Replace** អនុញ្ញាតឱ្យអ្នកបិទភ្ជាប់ key ថ្មី។ **Cancel** រក្សា key ចាស់។
- **Remove** លុប key ដែលបានរក្សាទុក។
- **Get a key** បើកទំព័រដែលសេវានោះផ្តល់ key ឱ្យអ្នក។
- *A key is saved, but this version of Kroma can't read it from the keychain.* មានន័យថា key នៅតែរក្សាទុក តែ Kroma ច្បាប់នេះមិនត្រូវបានអនុញ្ញាតឱ្យអានវា (អាចកើតឡើងលើ Mac ក្រោយការធ្វើបច្ចុប្បន្នភាព)។ បិទភ្ជាប់វាម្តងទៀត ឬបើក Kroma ម្តងទៀត ហើយជ្រើស **Always Allow** ពេល Mac សួរ។ key ដែលរក្សាទុកមិនដែលត្រូវបានជំនួសដោយ key ទទេទេ។

key ត្រូវបានអ៊ិនគ្រីបដោយ keychain នៃប្រព័ន្ធរបស់អ្នក ហើយផ្ញើទៅតែសេវារបស់វាប៉ុណ្ណោះ។ មើល [គម្រោង និងឯកសារ](projects-and-files#key-របស់អ្នកនៅលើថាស)។
