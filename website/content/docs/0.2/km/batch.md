**Batch** ធ្វើការងារទាំងមូលឱ្យវីដេអូច្រើនក្នុងពេលតែមួយ។ អ្នកជ្រើសជំហានតែម្តង (អក្សររត់ ការបកប្រែ ការដាក់សំឡេង រចនាប័ទ្ម ការនាំចេញ គម្រប និងអត្ថបទបង្ហោះ) ចុច **Process** រួចវីដេអូនីមួយៗឆ្លងកាត់ជំហានទាំងនោះម្តងមួយៗ ខណៈអ្នកទៅធ្វើការងារផ្សេង។ វាឈប់មុនការបង្ហោះ ដើម្បីឱ្យអ្នកពិនិត្យវីដេអូនីមួយៗសិន។

បើកវាដោយ **Batch** នៅម៉ឺនុយខាងឆ្វេង។ ទំព័រនេះមានពីរផ្ទាំង៖ **Process** ជាកន្លែងធ្វើការលើវីដេអូ និង **Ready to post** ជាកន្លែងដែលវីដេអូរួចរាល់រង់ចាំ។

## រឿងភាគមួយទាំងមូល ពីដើមដល់ចប់

Batch ត្រូវបានធ្វើឡើងសម្រាប់រឿងភាគ។ របៀបប្រើធម្មតា៖

1. ក្នុង [Download Center](downloading#download-center) បិទភ្ជាប់តំណរបស់រឿងភាគ គូសធីកភាគដែលចង់បាន ហើយចុច **Download**។ ភាគនីមួយៗក្លាយជាគម្រោងមួយដាច់ដោយឡែក នៅក្នុងថតដែលមានឈ្មោះតាមរឿង។
2. បកប្រែភាគទីមួយដោយដៃក្នុងកម្មវិធីកែ ហើយកែឈ្មោះតួអង្គឱ្យត្រូវ។ Kroma បំពេញ [សទ្ទានុក្រមរឿងភាគ](translation#សទ្ទានុក្រមរឿងភាគ) ដូច្នេះភាគបន្ទាប់ៗសរសេរឈ្មោះដូចគ្នាទាំងអស់។
3. ក្នុង **Batch** បន្ថែមភាគផ្សេងទៀត ជ្រើសជំហាន ហើយចុច **Process**។
4. ពិនិត្យវីដេអូនីមួយៗក្នុង **Ready to post** ជ្រើសកន្លែងបង្ហោះ ហើយបង្ហោះ។

## បន្ថែមវីដេអូ

Batch ធ្វើការលើគម្រោង Kroma (ឯកសារ `.kroma`)។ នៅក្រោម **Videos to process**៖

- **Add from downloads** បង្ហាញវីដេអូដែលទាញយករួចពី Download Center ហើយមានគម្រោងរួចហើយ។ គូសធីកវីដេអូដែលអ្នកចង់បាន (**All** / **None** ជួយបាន) រួចចុច **Add … to the list**។ វីដេអូដែលមានក្នុងបញ្ជីរួចហើយ សរសេរថា **In the list**។
- **Add projects…** ជ្រើសឯកសារគម្រោងណាមួយក៏បាន។ ប្រអប់នេះបើកនៅថត `projects` ជាកន្លែងដែល Download Center បង្កើតគម្រោង។

អ្នកក៏អាចផ្ញើវីដេអូពី Download Center បានដែរ៖ គូសធីកវីដេអូដែលទាញយករួចក្នុងជួររង់ចាំ ហើយចុច **Process … selected**។

គម្រោងមួយមិនត្រូវបានបន្ថែមពីរដងទេ។ វីដេអូដំណើរការម្តងមួយៗ តាមលំដាប់ដែលបានបន្ថែម។

## ជ្រើសជំហាន

**Steps** ដូចគ្នាសម្រាប់គ្រប់វីដេអូ។ បើកជំហានដែលអ្នកចង់បាន៖

| ជំហាន | ធ្វើអ្វី |
|---|---|
| **Subtitles** | យកឃ្លាដើម៖ អក្សររត់របស់គេហទំព័រ បើវីដេអូមាន បើមិនមានទេ ប្រើសំឡេងទៅជាអក្សរ។ កំណត់ **Spoken language** សម្រាប់សំឡេងទៅជាអក្សរ។ |
| **Translate** | បកប្រែគ្រប់ឃ្លាទៅ **Translate to** ដោយអ្នកបកប្រែដែលបានជ្រើសក្នុង **Settings → Translation**។ |
| **Find characters** | រកថាអ្នកណានិយាយឃ្លានីមួយៗ ដើម្បីឱ្យតួអង្គនីមួយៗមានសំឡេងផ្ទាល់ខ្លួន។ |
| **Voice-over** | អានឃ្លាដែលបកប្រែឮៗ។ **Voices**៖ **One voice** សម្រាប់គ្រប់ឃ្លា ឬ **Each character** (ត្រូវការ **Find characters**)។ ជ្រើស **Voice** (ជាមួយ **Each character** វាគឺ **Voice for lines with no character**)។ |
| **Remove original voices** | បង្ហាញពេលមានការដាក់សំឡេង។ រក្សាតន្ត្រី និងសំឡេងបែបផែននៅក្រោមសំឡេងថ្មី (របៀបលឿន)។ |
| **Hide original subtitles** | រកអក្សររត់ចិនដែលដិតជាប់ក្នុងវីដេអូ ហើយធ្វើឱ្យវាព្រិល ដើម្បីឱ្យឃើញតែអក្សររត់របស់អ្នក។ មើល [លាក់អក្សររត់ដើម](style-and-objects#លាក់អក្សររត់ដើម)។ |
| **Subtitle style** | ដាក់រចនាប័ទ្មតែមួយឱ្យគ្រប់វីដេអូ៖ preset ណាមួយក្នុងចំណោម 33 ឬរចនាប័ទ្មមួយក្នុង **My styles**។ បិទ = គម្រោងនីមួយៗរក្សារចនាប័ទ្មរបស់ខ្លួន។ |
| **Export** | គូស **16:9** (YouTube) និង/ឬ **9:16** (TikTok, Reels) ហើយជ្រើស **Export size**៖ **Small**, **Standard** ឬ **High**។ |
| **Make covers** | រូបគម្រប (thumbnail) សម្រាប់ភាគនីមួយៗ មានលេខភាគ (ភាគ ៥) និងចំណងជើងរឿង នៅក្បែរវីដេអូនាំចេញ។ ការរចនាយកតាម **Post → Cover** របស់គម្រោងនីមួយៗ។ មើល [គម្របភាគ](posting#គម្របភាគ)។ |
| **Write post text** | ចំណងជើង អត្ថបទ និង hashtag សម្រាប់វេទិកានីមួយៗ។ ត្រូវការ key Gemini ឬ Claude។ |

នៅក្រោមបញ្ជី Kroma សង្ខេបអ្វីដែលនឹងកើតឡើង ឧទាហរណ៍ *"5 steps: getting subtitles → translating → exporting 16:9 → exporting 9:16 → writing the posts. Then it waits in Ready to post."*

ជំហានតែងតែដំណើរការតាមលំដាប់នេះ។ ការដកសំឡេងដើមចេញ ធ្វើមុនការដាក់សំឡេង ដូច្នេះការដាក់សំឡេងមិនធ្វើវាម្តងទៀតទេ។ វីដេអូដែលគ្មានអក្សររត់ដិតជាប់ មិនមែនជាកំហុសទេ៖ **Hide original subtitles** កត់ថា *No burned-in subtitles found* ហើយ batch បន្តទៅមុខ។

ជម្រើសរបស់អ្នកត្រូវបានចងចាំសម្រាប់លើកក្រោយ។

## ដំណើរការ

ចុច **Process … videos**។ ពេលវាកំពុងដំណើរការ៖

- របារមួយនៅខាងលើបង្អួចសរសេរថា **Batch running** ព្រមទាំងវីដេអូ និងជំហានដែលវាកំពុងធ្វើ មាន **Open Batch** និង **Stop**។ របារស្ថានភាពនៅខាងក្រោមក៏បង្ហាញដែរ។
- Batch ប្រើកម្មវិធីកែដើម្បីធ្វើការ ដូច្នេះអ្នកមិនអាចប្រើកម្មវិធីកែបានទេ រហូតដល់វាចប់។ គម្រោងរបស់អ្នកផ្ទាល់ត្រូវបានទុកមួយឡែក ជាមួយប្រវត្តិ Undo ហើយវាត្រឡប់មកវិញពេលចប់។
- ក្រោយជំហាននីមួយៗ គម្រោងត្រូវបានរក្សាទុក។ បើមានអ្វីបរាជ័យ ការងារដែលធ្វើរួចមិនបាត់ទេ។
- អ្នកទទួលបានការជូនដំណឹងសម្រាប់វីដេអូនីមួយៗដែលរួចរាល់ និងសេចក្តីសង្ខេបនៅចុងបញ្ចប់ ដូចជា **Batch finished: 5 processed · 1 failed**។

**Stop** បោះបង់ជំហានដែលកំពុងដំណើរការ ហើយបញ្ឈប់ batch។ ចុច **Resume** ពេលក្រោយ ដើម្បីបន្តពីកន្លែងដែលវាឈប់។ បើអ្នកបិទ Kroma ពេល batch កំពុងដំណើរការ វីដេអូដែលកំពុងធ្វើនឹងបង្ហាញថាបានឈប់ ពេលអ្នកបើក Kroma ម្តងទៀត ហើយរង់ចាំអ្នកបន្ត។

## បញ្ជី

វីដេអូត្រូវបានដាក់ជាក្រុមតាមការដំណើរការ (រាល់ពេលចុច **Process**) ថ្មីបំផុតនៅខាងលើ ហើយ **Not started** នៅលើគេ។ ជួរនីមួយៗបង្ហាញវីដេអូ ស្លាកសម្រាប់ជំហាននីមួយៗ (រួច កំពុងធ្វើ បរាជ័យ ឬរំលង) និងស្ថានភាពរបស់វា៖ **Waiting**, ជំហានដែលកំពុងធ្វើ, **Failed at …**, **Stopped at …**, **Ready to post** ឬ **Posted**។

នៅខាងលើបញ្ជី៖

- តម្រង៖ **All**, **Running**, **Waiting**, **Failed**, **Ready to post** និង **Posted** ព្រមទាំង **Search videos**។
- **Retry failed** ដំណើរការវីដេអូដែលបរាជ័យទាំងអស់ម្តងទៀត ចាប់ពីជំហានដែលបរាជ័យ។
- **Clear finished** ដកវីដេអូដែលរួច និងបរាជ័យចេញពីបញ្ជី។ គម្រោង និងវីដេអូនាំចេញនៅដដែល។

នៅលើជួរនីមួយៗ៖

- **Retry from …** (វីដេអូបរាជ័យ) បន្តពីជំហានដែលបរាជ័យ។ ជំហានមុនៗនៅតែរួចដដែល។
- **Open project at …** បើកគម្រោងក្នុងកម្មវិធីកែ នៅផ្ទាំងរបស់ជំហាននោះ ដើម្បីកែដោយដៃ។
- **⋯** មាន **Show … export in Finder**, **Step details** និង **Remove from the list**។

បញ្ជីត្រូវបានរក្សាទុក ដូច្នេះក្រោយបើកឡើងវិញ អ្នកឃើញកន្លែងដែលអ្វីៗបានឈប់។ វារក្សាការដំណើរការ 20 ចុងក្រោយ។

### ព័ត៌មានលម្អិតនៃជំហាន

ចុចលើជួរមួយ (ឬ **See why** ក្បែរកំហុស) ដើម្បីបើកព័ត៌មានលម្អិតនៅខាងស្តាំ៖ គ្រប់ជំហានពីលើចុះក្រោម ជាមួយពេលដែលវាដំណើរការ រយៈពេល និងអ្វីដែលវាបាននិយាយ (ចំនួនឃ្លាដែលបកប្រែ ឯកសារនាំចេញ ឬកំហុស)។

- ជំហានដែលបរាជ័យមាន **Retry from here** និង **Fix by hand**។
- ជំហានដែលរួចមាន **Run again from …** ដែលដំណើរការជំហាននោះ និងគ្រប់ជំហានបន្ទាប់ម្តងទៀត។ មានប្រយោជន៍ក្រោយពេលអ្នកប្តូរការកំណត់ ដូចជារចនាប័ទ្ម។
- **Exports** បង្ហាញឯកសារនាំចេញ នីមួយៗមាន **Show in Finder**។

## Ready to post

វីដេអូដែលរួចរាល់រង់ចាំនៅ **Ready to post**។ កាតនីមួយៗបង្ហាញវីដេអូ ឯកសារនាំចេញ និងជួរសម្រាប់ **YouTube**, **Facebook** និង **TikTok**៖

1. **គូសធីកកន្លែងដែលវាត្រូវទៅ។** គណនីដែលបានភ្ជាប់ត្រូវបានគូសធីករួចជាស្រេច។
2. **ជ្រើសទម្រង់** សម្រាប់វេទិកានីមួយៗ៖ **16:9** ឬ **9:16**។ YouTube ចាប់ផ្តើមនៅ 16:9, Facebook និង TikTok នៅ 9:16។ បើទម្រង់ណាមួយមិនទាន់នាំចេញ Kroma នាំចេញវាពេលអ្នកបង្ហោះ។
3. បើក **Post text** ដើម្បីអាន និងកែចំណងជើង អត្ថបទ និង hashtag សម្រាប់វេទិកានីមួយៗ។
4. ចុច **Post** លើកាត ឬគូសធីកកាតច្រើន ហើយចុច **Post selected** នៅខាងលើ។

**YouTube visibility** (**Public**, **Unlisted** ឬ **Private**) និង **TikTok** (**Post now** ឬ **To drafts**) នៅខាងលើ អនុវត្តចំពោះអ្វីៗទាំងអស់ដែលអ្នកបង្ហោះពីទីនេះ។ វេទិកានីមួយៗទទួលឯកសារតាមទម្រង់របស់វា។ Facebook ឡើងជា Reel ពេលវីដេអូរបស់វាជា 9:16 ហើយវែងមិនលើស 90 វិនាទី។

ក្រោយបង្ហោះ កាតបង្ហាញលទ្ធផលនៃវេទិកានីមួយៗ ហើយវីដេអូផ្លាស់ទៅ **Posted**។ **Post again** បង្ហោះវាម្តងទៀត ហើយ **Clear posted** ដកវីដេអូដែលបង្ហោះរួចចេញពីបញ្ជី។

ការបង្ហោះត្រូវការរៀបចំ Upload-Post តែម្តង៖ មើល [ការបង្ហោះ](posting#រៀបចំការបង្ហោះ-តែម្តង)។ សូមបង្ហោះតែវីដេអូដែលអ្នកមានសិទ្ធិប្រើប៉ុណ្ណោះ។
