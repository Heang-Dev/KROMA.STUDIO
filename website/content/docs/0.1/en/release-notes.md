## How versions are numbered

A Kroma version has three numbers, like **0.1.3**:

| Part | In 0.1.3 | Means |
|---|---|---|
| First | 0 | Kroma is still young. It becomes 1 at the first stable release. |
| Second | 1 | The series. These docs are for the 0.1 series. A new series can bring bigger changes, and gets its own docs. |
| Third | 3 | A release within the series: fixes and new features. Every 0.1.x release opens projects from earlier 0.1.x releases. |

Numbers are compared one part at a time, so 0.1.10 is newer than 0.1.9.

## Which version you have

Open **Settings → About** (⌘, or Ctrl+, then **About**). The top line shows it, for example **Kroma Studio 0.1.3**. Under **Updates**, the line next to **Check for updates** also says whether you have the latest version.

## Getting a new version

From 0.1.1 on, Kroma updates itself: see [Updates](updates). To move from 0.1.0, or to install a specific version by hand, see the [Upgrade guide](upgrade). Every release, with its downloads, is also on [GitHub Releases](https://github.com/Heang-Dev/kroma/releases).
