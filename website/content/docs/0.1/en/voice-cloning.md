Clone a voice to use it for any character.

## Record in the app

1. Open **Voices** → **Clone voice** → **Record now**.
2. Read the text on screen aloud (about 15 seconds), in a quiet room, with the microphone about a hand's width away.
3. Listen back. Press **Record again** if it isn't clear.
4. Give it a name, confirm you have the right to use the voice, and press **Clone voice**.

Because you read a known text, cloning takes only seconds.

## Use a file

Choose **Use a file** to clone from 5–20 seconds of one person speaking clearly, with no music.

## Importing from Khmer Voice Studio

**Voices → Import from KVS** copies voices from your Khmer Voice Studio dashboard. Preset voices come over by themselves; cloned voices need your confirmation.

## Consent

Only clone **your own voice**, or a voice you have the speaker's permission to use. Never use a voice to pretend to be someone, including singers and other public figures.
