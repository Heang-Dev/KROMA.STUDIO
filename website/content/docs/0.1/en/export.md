Press **Export** at the top right, or the **Export** step. Each size shows its estimated file size.

| Size | About (5 minutes, 1080p) | For |
|---|---|---|
| Small | 75 MB | TikTok and Facebook (they shrink videos anyway) |
| Standard | 150 MB | YouTube; quick to export |
| High | 140 MB+ | The best quality, about 3× slower |

Exports go into your export folder (**Settings → Folders**), or ask where to save each time.

If an export fails, the full log is saved as `last-export-error.log` in Kroma's settings folder: attach it to a [GitHub issue](https://github.com/Heang-Dev/KROMA.STUDIO/issues).
