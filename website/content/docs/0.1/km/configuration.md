Kroma ប្រើសេវា AI ជាមួយ **key ផ្ទាល់ខ្លួនរបស់អ្នក**៖ អ្នកមិនបង់អ្វីឱ្យ Kroma ទេ គឺបង់តែអ្វីដែលសេវានោះគិតប៉ុណ្ណោះ ដែលភាគច្រើនឥតគិតថ្លៃនៅពេលចាប់ផ្តើម។ key ត្រូវបានអ៊ិនគ្រីបដោយ keychain នៃប្រព័ន្ធរបស់អ្នក ហើយផ្ញើទៅតែសេវាដែលវាជាកម្មសិទ្ធិប៉ុណ្ណោះ។

ពេលបើក Kroma លើកដំបូង វាបើក **Settings → Translation** ឱ្យ។

## ការបកប្រែ និងការសរសេរការបង្ហោះ

ជ្រើសអ្នកបកប្រែនៅក្នុង **Settings → Translation**៖

| អ្នកបកប្រែ | តម្លៃ | ចំណាំ |
|---|---|---|
| Gemini | កម្រិតឥតគិតថ្លៃ | លំនាំដើម។ យក key នៅ [Google AI Studio](https://aistudio.google.com/apikey)។ សរសេរការបង្ហោះលើបណ្តាញសង្គមឱ្យផងដែរ។ |
| Google Translate | ឥតគិតថ្លៃ មិនត្រូវការ key | ពាក្យពេចន៍ធម្មតា។ ល្អនៅពេលអ្នកគ្មាន key។ |
| Claude | បង់ប្រាក់ | ភាសាខ្មែរធម្មជាតិបំផុត ល្អបំផុតជាមួយឈ្មោះ និងសំនៀង។ |

## បំប្លែងសំឡេងទៅជាអក្សរ

នៅក្នុង **Settings → Speech to Text** បន្ថែម [key Groq](https://console.groq.com/keys) ឥតគិតថ្លៃ។ Groq ដំណើរការ Whisper large-v3 ហើយបំប្លែងភាពយន្តមួយរឿងក្នុងរយៈពេលប៉ុន្មានវិនាទី។ Gemini (ជាមួយ key Gemini របស់អ្នក) និង OpenAI ក៏ប្រើបានដែរ។

## ការទាញយក

គេហទំព័រខ្លះផ្តល់គុណភាពខ្ពស់ ឬវីដេអូសម្រាប់សមាជិក តែពេលអ្នកចូលគណនីប៉ុណ្ណោះ។ នៅក្នុង **Settings → Downloads** ជ្រើសកម្មវិធីរុករកដែលអ្នកបានចូលគណនី ហើយ Kroma ប្រើការចូលគណនីនោះសម្រាប់ការទាញយក។

## ថត

**Settings → Folders** កំណត់កន្លែងដែលវីដេអូនាំចេញ និងវីដេអូទាញយកត្រូវទៅ។ លំនាំដើម៖ ថត Videos (ឬ Movies) របស់អ្នក → Kroma Studio។
