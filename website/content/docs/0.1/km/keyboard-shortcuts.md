ផ្លូវកាត់ក្តារចុចទាំងអស់នៅក្នុង Kroma Studio នៅកន្លែងតែមួយ។ លើ Mac អ្នកប្រើគ្រាប់ចុច **⌘** (Command)។ លើ Windows និង Linux អ្នកប្រើ **Ctrl** ជំនួសវិញ។ បើគ្រាប់ចុចដូចគ្នាលើគ្រប់ប្រព័ន្ធ តារាងបង្ហាញវាតែម្តង។

អ្នកក៏អាចមើលផ្លូវកាត់របស់កម្មវិធីកែសម្រួលនៅក្នុងកម្មវិធីផ្ទាល់បានដែរ៖ បើក **Settings → Shortcuts**។ លើ Windows និង Linux បញ្ជីនោះ និងស្លាកពន្យល់លើប៊ូតុង បង្ហាញ **Ctrl** និង **Shift** ជំនួសនិមិត្តសញ្ញារបស់ Mac រួចស្រេច។

## របៀបអានគ្រាប់ចុច

| និមិត្តសញ្ញា | គ្រាប់ចុចលើ Mac | គ្រាប់ចុចលើ Windows / Linux |
|---|---|---|
| ⌘ | Command | Ctrl |
| ⇧ | Shift | Shift |
| ⌥ | Option | Alt |
| ⌫ | Delete (លុបថយក្រោយ) | Backspace |

## គម្រោង

ផ្លូវកាត់ទាំងនេះដំណើរការគ្រប់ទីកន្លែងក្នុងកម្មវិធីកែសម្រួល សូម្បីតែពេលអ្នកកំពុងវាយអក្សរក្នុងប្រអប់អត្ថបទក៏ដោយ។

| សកម្មភាព | macOS | Windows / Linux |
|---|---|---|
| គម្រោងថ្មី | ⌘N | Ctrl+N |
| បើកគម្រោង | ⌘O | Ctrl+O |
| រក្សាទុកគម្រោង | ⌘S | Ctrl+S |
| រក្សាទុកគម្រោងជាឯកសារថ្មី | ⇧⌘S | Ctrl+Shift+S |
| បើក Settings | ⌘, | Ctrl+, |

**Save project** រក្សាទុកទៅក្នុងឯកសាររបស់គម្រោង។ លើកដំបូង វាសួរថាត្រូវរក្សាទុកនៅឯណា។ **រក្សាទុកជាឯកសារថ្មី** សួររាល់ពេល ដូច្នេះអ្នកអាចរក្សាច្បាប់ចម្លងមួយក្រោមឈ្មោះថ្មី។ មើល [គម្រោង និងឯកសារ](projects-and-files#ការរក្សាទុក)។

## ការកែសម្រួល

| សកម្មភាព | macOS | Windows / Linux |
|---|---|---|
| មិនធ្វើវិញ (Undo) | ⌘Z | Ctrl+Z |
| ធ្វើវិញ (Redo) | ⇧⌘Z | Ctrl+Shift+Z |
| កាត់ឃ្លីបនៅត្រង់ playhead | S | S |
| លុបឃ្លីប បន្ទាត់អក្សររត់ ឬវត្ថុដែលបានជ្រើស | ⌫ ឬ Delete | Backspace ឬ Delete |
| លែងជ្រើស | Esc | Esc |

Undo ចងចាំការផ្លាស់ប្តូរ ១០០ ចុងក្រោយរបស់អ្នក។ ការបើក ឬចាប់ផ្តើមគម្រោងមួយ លុបប្រវត្តិនោះចោល។

## ការចាក់

| សកម្មភាព | macOS | Windows / Linux |
|---|---|---|
| ចាក់ / ផ្អាក | Space | Space |
| ថយក្រោយមួយហ្វ្រេម | ← | ← |
| ទៅមុខមួយហ្វ្រេម | → | → |
| ថយក្រោយ ៥ វិនាទី | ⇧← | Shift+← |
| ទៅមុខ ៥ វិនាទី | ⇧→ | Shift+→ |

Space ចាក់បាន តែពេលមានវីដេអូនៅលើ timeline ប៉ុណ្ណោះ។ មួយហ្វ្រេមស្មើនឹង ១/៣០ វិនាទី។

## Timeline

| សកម្មភាព | macOS | Windows / Linux |
|---|---|---|
| ពង្រីក ឬបង្រួម timeline ជុំវិញទស្សន៍ទ្រនិច | ⌘ + រំកិល ឬច្បិចលើ trackpad | Ctrl + រំកិល |
| ផ្លាស់ទី playhead | ចុច ឬអូសក្នុង timeline | ចុច ឬអូសក្នុង timeline |

ប៊ូតុងខាងលើ timeline ក៏ពង្រីកបង្រួមបានដែរ (**Zoom in**, **Zoom out**, **Fit the whole video**)។

## ផ្ទាំង

អ្នកអាចប្តូរទំហំផ្ទាំងឧបករណ៍ បញ្ជីអក្សររត់ និង timeline ដោយអូសគែមរបស់វា។ គែមនីមួយៗក៏ប្រើពីក្តារចុចបានដែរ៖

1. ចុច Tab រហូតដល់គែមដែលអ្នកចង់បានត្រូវបានរំលេច។
2. ប្រើគ្រាប់ចុចព្រួញ ដើម្បីធ្វើឱ្យផ្ទាំងធំ ឬតូចជាងមុន (១៦ ភីកសែលក្នុងមួយចុច)។
3. ចុចពីរដងលើគែម ដើម្បីដាក់ផ្ទាំងនោះមកទំហំធម្មតាវិញ។

## ទំហំផ្ទៃកម្មវិធី និងផ្ទាំងវីនដូ

| សកម្មភាព | macOS | Windows / Linux |
|---|---|---|
| ផ្ទៃកម្មវិធីធំជាងមុន | ⌘+ ឬ ⌘= | Ctrl+ + ឬ Ctrl+= |
| ផ្ទៃកម្មវិធីតូចជាងមុន | ⌘− | Ctrl+− |
| ផ្ទៃកម្មវិធី 100% | ⌘0 | Ctrl+0 |
| វីនដូថ្មី | ⇧⌘N | Ctrl+Shift+N |
| បិទវីនដូ | ⌘W | Ctrl+W |
| បង្រួមវីនដូ | ⌘M | Ctrl+M |
| បើក / បិទពេញអេក្រង់ | Control+⌘F | F11 |
| ចេញពី Kroma | ⌘Q | **File → Exit** |

ទំហំផ្ទៃកម្មវិធីប្តូរនៅគ្រប់វីនដូដែលកំពុងបើក។ វាឡើងចុះជាជំហាន 70%, 80%, 90%, 100%, 110%, 125% និង 140% ហើយមានសារខ្លីបង្ហាញទំហំថ្មី។ អ្នកក៏អាចជ្រើសទំហំនៅក្នុង [Settings → Appearance](settings#appearance) បានដែរ។

## នៅក្នុង Settings

| សកម្មភាព | macOS | Windows / Linux |
|---|---|---|
| ស្វែងរកការកំណត់ | ⌘F | Ctrl+F |
| បើកលទ្ធផលស្វែងរកទីមួយ | Enter | Enter |
| សម្អាតការស្វែងរក ឬត្រឡប់ទៅកម្មវិធីកែសម្រួល | Esc | Esc |

ចុច Esc ម្តង ដើម្បីសម្អាតអ្វីដែលអ្នកបានវាយក្នុងប្រអប់ស្វែងរក ហើយចុចម្តងទៀត ដើម្បីត្រឡប់ទៅកម្មវិធីកែសម្រួល។

## ប្រអប់អត្ថបទ

ពេលអ្នកវាយក្នុងប្រអប់អត្ថបទ (បន្ទាត់អក្សររត់ ឈ្មោះគម្រោង ឬការបង្ហោះ) គ្រាប់ចុចអត្ថបទធម្មតាដំណើរការ៖ ចម្លង កាត់ បិទភ្ជាប់ ជ្រើសទាំងអស់ និង undo ឬ redo **នៅក្នុងប្រអប់នោះ**។ ផ្លូវកាត់គ្រាប់ចុចតែមួយរបស់កម្មវិធីកែសម្រួល (Space, S, Delete, ព្រួញ) ត្រូវបានបិទពេលអ្នកវាយ ដូច្នេះវាមិនរំខានការសរសេររបស់អ្នកទេ។ ចុចនៅខាងក្រៅប្រអប់ ឬចុច Tab ដើម្បីប្រើវាវិញ។

ផ្លូវកាត់របស់កម្មវិធីកែសម្រួលក៏ផ្អាកដែរ ពេលម៉ឺនុយ ឬប្រអប់សន្ទនាកំពុងបើក និងពេលអ្នកនៅទំព័រ Settings ឬ Voices។
