ទំព័រនេះពន្យល់ពីរូបរាងវីដេអូរបស់អ្នក៖ រាងរបស់វា រូបរាងអក្សររត់ និងអ្វីៗដែលអ្នកដាក់ពីលើរូបភាព ដូចជាការធ្វើឱ្យអក្សររត់ចាស់ព្រិល ឬឡូហ្គោរបស់អ្នក។ ការមើលជាមុននៅកណ្តាល តែងតែបង្ហាញដូចវីដេអូនាំចេញពិតៗ ព្រោះទាំងពីរត្រូវបានគូរតាមរបៀបដូចគ្នា។

## ទម្រង់

បើក **Style**។ នៅខាងលើ **Format** កំណត់រាងនៃវីដេអូដែលរួចរាល់៖

| ទម្រង់ | សម្រាប់ | ទំហំនាំចេញ |
|---|---|---|
| **16:9** | YouTube, Facebook | 1920 × 1080 |
| **9:16** | TikTok, Reels | 1080 × 1920 |
| **1:1** | Feed | 1080 × 1080 |

គម្រោងថ្មីចាប់ផ្តើមជា **16:9**។ បើវីដេអូដំបូងរបស់អ្នកជាវីដេអូបញ្ឈរ Kroma ប្តូរទៅ **9:16** ដោយខ្លួនឯង។ ប៊ូតុង **Export** នៅខាងស្តាំខាងលើបង្ហាញទម្រង់បច្ចុប្បន្ន ដូចជា **Export 9:16**។

អ្នកអាចនាំចេញគម្រោងដដែលក្នុងទម្រង់នីមួយៗ៖ ប្តូរទម្រង់ នាំចេញ ប្តូរម្តងទៀត ហើយនាំចេញម្តងទៀត។

### ពេលវីដេអូមិនត្រូវទំហំ

វីដេអូទទឹងក្នុងទម្រង់បញ្ឈរ (ឬផ្ទុយមកវិញ) ទុកកន្លែងទំនេរ។ **When it doesn't fit** សម្រេចថាអ្វីបំពេញកន្លែងនោះ៖

- **Blur**៖ ច្បាប់ចម្លងវីដេអូដែលព្រិល និងងងឹតបន្តិច បំពេញកន្លែងនៅខាងក្រោយ។ នេះជារូបរាងទូទៅសម្រាប់វីដេអូទទឹងក្នុងការបង្ហោះបញ្ឈរ។ វាជាលំនាំដើម។
- **Bars**៖ គែមខ្មៅ។
- **Crop**៖ វីដេអូត្រូវបានពង្រីកឱ្យពេញស៊ុម ហើយគែមត្រូវបានកាត់ចេញ។

## រចនាប័ទ្មអក្សររត់

ផ្នែក **Subtitle style** ប្តូររូបរាងអក្សររត់ទាំងអស់។

### រូបរាងស្រាប់

**Preset** ផ្តល់រូបរាងរៀបចំស្រាប់ ដោយចុចតែម្តង៖

| Preset | រូបរាង |
|---|---|
| **Classic** | អក្សរស មានគែមខ្មៅ |
| **Yellow** | អក្សរលឿង មានគែមខ្មៅ |
| **Box** | អក្សរស លើប្រអប់ងងឹតថ្លា គ្មានគែម |
| **TikTok** | អក្សរសដិត មានគែមខ្មៅក្រាស់ជាង |

Preset កំណត់តែពណ៌ គែម និងប្រអប់ប៉ុណ្ណោះ។ អ្នកអាចប្តូរអ្វីក៏បានក្រោយពេលជ្រើស។ បើអ្នកប្តូរអ្វីដែល preset បានកំណត់ នឹងគ្មាន preset ណាបង្ហាញថាត្រូវបានជ្រើសទេ។

### ការកំណត់ទាំងអស់

| ការកំណត់ | ធ្វើអ្វី | លំនាំដើម |
|---|---|---|
| **Size** | ទំហំអក្សរ ពី 2.5% ដល់ 10% នៃជ្រុងខ្លីរបស់ស៊ុម | 5.2% |
| **Position** | អក្សររត់នៅទាបប៉ុណ្ណាលើអេក្រង់ ពី 20% ដល់ 98% (បាតអក្សរនៅត្រង់នេះ) | 90% |
| **Outline** | កម្រាស់គែមជុំវិញអក្សរនីមួយៗ ពី **Off** ដល់ 25 | 12 |
| **Text colour** | ពណ៌អក្សរ | ស |
| **Outline colour** | ពណ៌គែម | ខ្មៅ |
| **Bold** | អក្សរដិត | បើក |
| **Dark box behind the text** | ប្រអប់ងងឹតជ្រុងមូលនៅក្រោយឃ្លានីមួយៗ ងាយអានលើរូបភាពច្របូកច្របល់ | បិទ |
| **Bilingual** | បង្ហាញឃ្លាដើម (ឧទាហរណ៍ភាសាចិន) ពីលើការបកប្រែ តូចជាង និងពណ៌លឿងស្រាល | បិទ |

សម្រាប់ពណ៌ ចុចលើប្រអប់ពណ៌ ដើម្បីបើកឧបករណ៍ជ្រើសពណ៌។ កូដពណ៌ (ដូចជា `#FFFFFF`) បង្ហាញនៅក្បែរវា។

អក្សររត់ប្រើពុម្ពអក្សរ Kantumruy Pro ដែលមកជាមួយ Kroma ដូច្នេះអក្សរខ្មែរតែងតែត្រឹមត្រូវ។ ឃ្លាវែងចុះជាពីរបន្ទាត់ ដោយបំបែកតែនៅចន្លោះពាក្យប៉ុណ្ណោះ។ ពេលបន្ទាត់ទីពីរខ្លីពេក Kroma ធ្វើឱ្យបន្ទាត់ទាំងពីរស្មើគ្នា។

រចនាប័ទ្មត្រូវបានរក្សាទុកជាមួយគម្រោង។ ពេលអ្នកប្តូរវា ជំហាន **Style** ក្នុងរបារជំហានប្រែជាពណ៌បៃតង។

## បិទអក្សររត់ដើម

វីដេអូជាច្រើន ជាពិសេសរឿងភាគចិន មានអក្សររត់ដិតជាប់ក្នុងរូបភាព។ អក្សររត់ថ្មីរបស់អ្នកនឹងនៅពីលើវា ហើយពិបាកអាន។

1. បើក **Objects**។
2. ចុច **Cover original subtitles**។

Kroma បន្ថែមប្រអប់ព្រិលមួយលើផ្នែកខាងក្រោមនៃរូបភាព ជាកន្លែងដែលអក្សររត់ដិតជាប់តែងតែនៅ។ វាដើរតាមរូបភាព ដូច្នេះវានៅត្រូវកន្លែងទាំងជាមួយ **Blur** ឬ **Bars**។ បើអក្សររត់ចាស់នៅខ្ពស់ ឬទាបជាងបន្តិច អូសប្រអប់ដើម្បីផ្លាស់ទី ហើយអូសជ្រុងរបស់វាដើម្បីប្តូរទំហំ។ ធ្វើឱ្យវាព្រិលខ្លាំង ឬស្រាលជាងដោយរបារ **Blur**។

## វត្ថុ

**Objects** អនុញ្ញាតឱ្យអ្នកដាក់អ្វីៗពីលើវីដេអូ។ អក្សររត់របស់អ្នកតែងតែនៅពីលើវា។

នៅក្រោម **Add to the video**៖

| ប៊ូតុង | អ្វីដែលអ្នកទទួលបាន |
|---|---|
| **Cover original subtitles** | ប្រអប់ព្រិលលើអក្សររត់ចាស់ (មើលខាងលើ) |
| **Blur area** | ប្រអប់ព្រិលនៅកណ្តាលរូបភាព ដើម្បីលាក់ watermark មុខមនុស្ស ឬស្លាកលេខ |
| **Image / logo** | ឡូហ្គោរបស់អ្នក ឬរបស់អ្នកឧបត្ថម្ភ ពីឯកសារ `.png`, `.jpg`, `.jpeg`, `.webp` ឬ `.gif`។ វាចាប់ផ្តើមនៅជ្រុងខាងស្តាំខាងលើ។ |
| **Text** | អក្សរខ្លីមួយបន្ទាត់ ដូចជាការអំពាវនាវ។ វាចាប់ផ្តើមនៅខាងឆ្វេងខាងលើ ដោយសរសេរថា "Sponsored by …"។ |

ប៊ូតុងទាំងនេះប្រើមិនបាន រហូតដល់មានវីដេអូនៅលើ timeline។

### ផ្លាស់ទី និងប្តូរទំហំ

នៅលើការមើលជាមុន៖

- ចុចលើវត្ថុមួយ ដើម្បីជ្រើសវា។ វាមានគែមដាច់ៗពណ៌ស។
- អូសវា ដើម្បីផ្លាស់ទី។
- អូសចំណុចមូលនៅជ្រុងខាងស្តាំខាងក្រោម ដើម្បីប្តូរទំហំ។

រូបភាពរក្សារាងរបស់វា ពេលអ្នកប្តូរទំហំ។ សម្រាប់អក្សរ ការធ្វើឱ្យប្រអប់ខ្ពស់ជាង ធ្វើឱ្យអក្សរធំជាង ចំណែកទទឹងធ្វើតាមអក្សរ។

### ការកំណត់វត្ថុ

ពេលវត្ថុមួយត្រូវបានជ្រើស ការកំណត់របស់វាបង្ហាញនៅខាងក្រោមផ្ទាំង **Objects**៖

| ការកំណត់ | សម្រាប់ | ធ្វើអ្វី |
|---|---|---|
| **Blur** | ប្រអប់ព្រិល | កម្រិតព្រិល ពី 2 ដល់ 40 |
| **Opacity** | រូបភាព និងអក្សរ | កម្រិតថ្លា ពី 10% ដល់ 100% |
| **Text** | អក្សរ | ពាក្យដែលត្រូវបង្ហាញ |
| **Colours** | អក្សរ | ប្រអប់ពណ៌ពីរ៖ ពណ៌អក្សរ បន្ទាប់មកពណ៌ផ្ទៃខាងក្រោយ |
| **Background** | អក្សរ | ប្រអប់ជ្រុងមូលនៅក្រោយអក្សរ។ ពេលបិទ អក្សរមានគែមងងឹតស្តើងជំនួសវិញ។ |
| **Bold** | អក្សរ | អក្សរដិត |
| **Whole video** | ទាំងអស់ | បើក៖ បង្ហាញពេញវីដេអូ |

### បង្ហាញវត្ថុតែមួយផ្នែកនៃវីដេអូ

វត្ថុនីមួយៗចាប់ផ្តើមដោយបង្ហាញពេញវីដេអូ។ ដើម្បីបង្ហាញវាតែមួយរយៈ៖

1. ជ្រើសវត្ថុនោះ។
2. បិទ **Whole video**។ ឥឡូវវាចាប់ផ្តើមត្រង់ក្បាលចាក់ ហើយនៅរហូតដល់ចប់។ កុងតាក់បង្ហាញពេលវេលា ដូចជា *Shown 00:10 → end*។
3. ផ្លាស់ក្បាលចាក់ ហើយចុច **Start here** ឬ **End here** នៅក្រោម **Timing**។

### បញ្ជីវត្ថុ

**On the video** រាយវត្ថុទាំងអស់ដែលអ្នកបានបន្ថែម។ ចុចលើឈ្មោះ ដើម្បីជ្រើសវា។ ប្រើប៊ូតុងភ្នែក ដើម្បី **Hide** (លាក់) ឬ **Show** (បង្ហាញ) វត្ថុមួយ (វត្ថុដែលលាក់មិនត្រូវបាននាំចេញទេ) និងធុងសំរាម ដើម្បី **Delete** វា។ អ្នកក៏អាចជ្រើសវត្ថុ ហើយចុច `Delete` ដែរ។
