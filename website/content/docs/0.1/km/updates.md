Kroma ធ្វើបច្ចុប្បន្នភាពដោយខ្លួនឯង។ កំណែថ្មីទាញយកនៅពីក្រោយ ពេលអ្នកកំពុងធ្វើការ ហើយអ្នកជ្រើសពេលបើកឡើងវិញ។ គម្រោងរបស់អ្នកត្រូវបានរក្សាទុក ហើយបើកមកវិញក្រោយពេលបើកឡើងវិញ។

## របៀបដែលវាដំណើរការ

1. **Kroma ពិនិត្យរកកំណែថ្មី។** ការពិនិត្យលើកដំបូងកើតឡើងប៉ុន្មានវិនាទីក្រោយ Kroma ចាប់ផ្តើម បន្ទាប់មករៀងរាល់ ៤ ម៉ោងម្តង ពេលវាកំពុងបើក។ កំណែថ្មីមកពី [GitHub Releases](https://github.com/Heang-Dev/kroma/releases)។
2. **វាទាញយកនៅពីក្រោយ។** ប្រអប់មួយលេចឡើងនៅជ្រុងខាងក្រោមស្តាំ៖ **Downloading Kroma 0.1.4**, "It downloads in the background. Keep working." ជាមួយរបារដំណើរការ និងភាគរយ។
3. **វារួចរាល់។** ប្រអប់ប្តូរទៅជា **Kroma 0.1.4 is ready**, "Restart to finish updating. Your project is saved and opens again." វាមានប៊ូតុងពីរ៖
   - **Restart to update**៖ Kroma បិទ ដំឡើងកំណែថ្មី ហើយបើកឡើងវិញជាមួយគម្រោងរបស់អ្នក។
   - **Later**៖ លាក់ប្រអប់។ អ្នកអាចបន្តធ្វើការបានយូរតាមចិត្ត។

បើ Kroma ជាកំណែចុងក្រោយស្រាប់ គ្មានអ្វីលេចឡើងទេ។

## ក្រោយពេលចុច Later

ប្រអប់នៅតែលាក់សម្រាប់កំណែនោះ ប៉ុន្តែការធ្វើបច្ចុប្បន្នភាពមិនបាត់ទេ។ ពាក្យ **Restart to update** តូចពណ៌បៃតង នៅតែមាននៅលើរបារជំហានខាងក្រោមបង្អួច ផ្នែកខាងស្តាំ ក្បែរប៊ូតុង **Next**។ ចុចវា ដើម្បីបង្ហាញប្រអប់មកវិញ។

បើអ្នកលាក់ប្រអប់ពេលវាកំពុងទាញយក របារជំហានបង្ហាញ **Updating** ជាមួយភាគរយជំនួសវិញ។

អ្នកក៏អាចលាក់ប្រអប់ដោយចុច **×** នៅជ្រុងខាងលើស្តាំរបស់វា។ វាដូចគ្នានឹង **Later** ដែរ។

## ការកំណត់ការធ្វើបច្ចុប្បន្នភាព

បើក **Settings → About**។ ប្រអប់ **Updates** មាន៖

| ការកំណត់ | តួនាទី |
|---|---|
| **Check for updates** · **Check now** | ស្វែងរកកំណែថ្មីភ្លាមៗ។ បន្ទាត់ខាងក្រោមវាប្រាប់ថាមានអ្វីកើតឡើង ឧទាហរណ៍ "You have the latest version (0.1.3)." ឬ "Downloading Kroma 0.1.4 · 45%"។ |
| **Update automatically** | បើកជាលំនាំដើម៖ កំណែថ្មីទាញយកនៅពីក្រោយ។ បើបិទ៖ Kroma គ្រាន់តែប្រាប់ថាមានកំណែថ្មី ហើយមិនទាញយកអ្វីទេ រហូតដល់អ្នកសុំ។ |
| **What's new** · **Changelog** | បើកបញ្ជីការផ្លាស់ប្តូរនៅលើគេហទំព័រ Kroma។ |

### ពេលបិទ Update automatically

Kroma នៅតែពិនិត្យពេលចាប់ផ្តើម និងរៀងរាល់ ៤ ម៉ោង។ ពេលមានកំណែថ្មី ប្រអប់សរសេរថា **Kroma 0.1.4 is available**, "A new version of Kroma is out." ជាមួយ **Download** និង **Later**។ ចុច **Download** ដើម្បីយកវា បន្ទាប់មកប្រអប់បង្ហាញដំណើរការ និង **Restart to update** ដូចធម្មតា។ ក្រោយពេលចុច **Later** របារជំហានបង្ហាញ **Update to 0.1.4** តូចមួយ ដែលអ្នកអាចចុចដើម្បីបង្ហាញប្រអប់មកវិញ។

ការចុច **Check now** ក្នុង Settings ទាញយកកំណែថ្មីភ្លាមៗ ទោះបីបិទការធ្វើបច្ចុប្បន្នភាពស្វ័យប្រវត្តិក៏ដោយ។

## របៀបដំឡើងលើប្រព័ន្ធនីមួយៗ

| ប្រព័ន្ធ | អ្វីកើតឡើងពេលចុច Restart to update |
|---|---|
| **macOS** | Kroma បានចម្លងកម្មវិធីថ្មីចេញពី `.dmg` ដែលទាញយករួចហើយ។ ពេលបើកឡើងវិញ វាប្តូរកម្មវិធីថ្មីចូលកន្លែង (ដោយរក្សាកម្មវិធីចាស់ទុក រហូតដល់ការចម្លងជោគជ័យ) ដកសញ្ញា «ទាញយកពីអ៊ីនធឺណិត» ហើយបើកវា។ អ្នកមិនចាំបាច់ប្រើពាក្យបញ្ជា `xattr` ម្តងទៀតទេ។ |
| **Windows** | កម្មវិធីដំឡើងថ្មីដំណើរការ ហើយ Kroma បើកឡើងវិញ។ |
| **Linux AppImage** | ឯកសារ AppImage ត្រូវបានជំនួសដោយឯកសារថ្មី ហើយ Kroma បើកឡើងវិញ។ |
| **Linux .deb** | ការដំឡើង `.deb` ត្រូវការពាក្យសម្ងាត់របស់អ្នក ដូច្នេះ Kroma មិនអាចធ្វើតែឯងបានទេ។ វាទាញយក `.deb` ថ្មី ហើយបើកវាក្នុងកម្មវិធីដំឡើងរបស់ប្រព័ន្ធ។ ដំឡើងវានៅទីនោះ រួចបើក Kroma ម្តងទៀត។ |

នៅលើ **Windows** និងជាមួយ **AppImage** បើអ្នកគ្រាន់តែបិទ Kroma ក្រោយពេលទាញយកការធ្វើបច្ចុប្បន្នភាពរួច វាដំឡើងពេល Kroma បិទ។ នៅលើ **Mac** កំណែថ្មីត្រូវបានដាក់ចូលកន្លែង តែពេលអ្នកចុច **Restart to update** ប៉ុណ្ណោះ។

| "No releases found yet." | GitHub គ្មានអ្វីផ្តល់ឱ្យទេ។ សាកម្តងទៀតពេលក្រោយ។ |

Drag the new Kroma Studio from the window that opened into Applications." | សម្រាប់តែ Mac។ Kroma មិនមានសិទ្ធិសរសេរក្នុងថតដែលវាដំណើរការ ឧទាហរណ៍ពេលអ្នកបើកវាផ្ទាល់ពី `.dmg`។ បង្អួច Finder មួយបើកឡើងជាមួយកម្មវិធីថ្មី៖ អូសវាចូលក្នុង **Applications**។ ចាប់ពីពេលនោះ សូមបើក Kroma ពី Applications។ |

ពេលការបើកឡើងវិញបរាជ័យ សារ **Couldn't update** លេចឡើងនៅជ្រុងខាងក្រោមស្តាំ ជាមួយមូលហេតុ។ អ្នកតែងតែអាច[ទាញយកកំណែចុងក្រោយដោយដៃ](https://github.com/Heang-Dev/kroma/releases/latest) ហើយដំឡើងវាជាន់លើកំណែចាស់ ដូចក្នុង [ការដំឡើង](installation)។ គម្រោង ការកំណត់ និង key របស់អ្នកនៅដដែល។

## កំណែចាស់ៗ

- កំណែមុន **0.1.1** មិនអាចធ្វើបច្ចុប្បន្នភាពដោយខ្លួនឯងបានទេ។ សូមទាញយកកំណែចុងក្រោយម្តងដោយដៃ។
- នៅលើ Windows និង Linux ការធ្វើបច្ចុប្បន្នភាពស្វ័យប្រវត្តិដំណើរការចាប់ពី **0.1.2**។ បើអ្នកមាន 0.1.1 លើ Windows ឬ Linux សូមទាញយកកំណែចុងក្រោយម្តងដោយដៃដែរ។

## ប្រើកំណែចាស់

បិទ **Update automatically** ហើយកុំចុច **Download** លើប្រអប់។ ដើម្បីអានឯកសារណែនាំសម្រាប់កំណែរបស់អ្នក ប្រើម៉ឺនុយកំណែនៅខាងលើរបារចំហៀងនៃឯកសារណែនាំ។ [កំណត់ចំណាំកំណែ](release-notes) នៃកំណែនីមួយៗ បង្ហាញអ្វីដែលបានផ្លាស់ប្តូរ ហើយ [ការដំឡើងកំណែ](upgrade) ពន្យល់អ្វីដែលអ្នកត្រូវធ្វើពេលប្តូរទៅកំណែថ្មី។
