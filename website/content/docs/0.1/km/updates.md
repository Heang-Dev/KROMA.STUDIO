Kroma ធ្វើបច្ចុប្បន្នភាពដោយខ្លួនឯង។

## របៀបដែលវាដំណើរការ

1. Kroma ពិនិត្យ [GitHub Releases](https://github.com/Heang-Dev/kroma/releases) ពេលវាចាប់ផ្តើម និងរៀងរាល់ ៤ ម៉ោងម្តង។
2. កំណែថ្មីទាញយកនៅពីក្រោយ ហើយប្រអប់មួយនៅជ្រុងខាងក្រោមស្តាំបង្ហាញដំណើរការ។
3. ពេលវារួចរាល់ ប្រអប់នោះបង្ហាញប៊ូតុង **Restart to update**។ ចុចវាពេលណាក៏បាន៖ Kroma បើកឡើងវិញជាមួយកំណែថ្មី ហើយគម្រោងរបស់អ្នកបើកមកវិញ។ **Later** លាក់ប្រអប់ ហើយ **Restart to update** នៅតែមាននៅរបារស្ថានភាពខាងក្រោម។

## ការកំណត់

នៅក្នុង **Settings → About → Updates**៖

- **Check now** ស្វែងរកកំណែថ្មីភ្លាមៗ។
- **Update automatically**៖ បើកជាលំនាំដើម។ បើបិទ៖ Kroma គ្រាន់តែប្រាប់អ្នកថាមានកំណែថ្មី ហើយអ្នកជ្រើសពេលទាញយកវា។

## របៀបដំឡើងលើប្រព័ន្ធនីមួយៗ

| ប្រព័ន្ធ | ការដំឡើង |
|---|---|
| macOS | Kroma ទាញយកកម្មវិធីថ្មី ហើយប្តូរវាចូលក្នុង Applications ពេលបើកឡើងវិញ |
| Windows | កម្មវិធីដំឡើងដំណើរការពេលបើកឡើងវិញ |
| Linux AppImage | AppImage ត្រូវបានជំនួសពេលបើកឡើងវិញ |
| Linux .deb | កញ្ចប់ `.deb` ថ្មីត្រូវបានទាញយក ហើយបើកក្នុងកម្មវិធីដំឡើងរបស់ប្រព័ន្ធ (វាសុំពាក្យសម្ងាត់របស់អ្នក) |

## ប្រើកំណែចាស់

បិទ **Update automatically** ហើយអានឯកសារណែនាំសម្រាប់កំណែរបស់អ្នក៖ ប្រើម៉ឺនុយកំណែនៅខាងលើរបារចំហៀង។ [កំណត់ចំណាំកំណែ](release-notes) នៃកំណែនីមួយៗ បង្ហាញអ្វីដែលបានផ្លាស់ប្តូរ។

កំណែមុន 0.1.1 មិនអាចធ្វើបច្ចុប្បន្នភាពដោយខ្លួនឯងបានទេ៖ សូមទាញយកកំណែចុងក្រោយម្តងដោយដៃ។
