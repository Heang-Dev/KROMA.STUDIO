## «Missing ffmpeg / yt-dlp»

លើ Mac៖ `brew install ffmpeg yt-dlp`។ កំណែ Windows និង Linux មានស្រាប់។ **Settings → About** បង្ហាញអ្វីដែលរកឃើញ។

## ទាញយកមិនបាន

គេហទំព័រខ្លះតម្រូវឱ្យអ្នកចូលគណនី៖ ជ្រើសកម្មវិធីរុករករបស់អ្នកនៅក្នុង **Settings → Downloads**។ វីដេអូដែលមាន DRM មិនអាចទាញយកបានទេ។ បើគេហទំព័រមួយបានផ្លាស់ប្តូរ សូមធ្វើបច្ចុប្បន្នភាព Kroma (yt-dlp ត្រូវបានធ្វើបច្ចុប្បន្នភាពជាមួយវា)។

## «ម៉ាស៊ីនសំឡេងមិនអាចភ្ជាប់បាន»

ចាប់ផ្តើម[ម៉ាស៊ីនសំឡេង](voice-engine) ហើយពិនិត្យអាសយដ្ឋានរបស់វានៅក្នុង **Settings → Voice Engine** ឬប្រើសំឡេងរហ័ស។

## ខ្ញុំនៅតែឮសំឡេងនិយាយដើម

ពិនិត្យថា **Voice → Mix → Remove the original voices** បានបើក ហើយ [uv](installation) បានដំឡើង។ នាំចេញម្តងទៀត។

## Gemini រវល់

key ឥតគិតថ្លៃមានកំណត់ប្រចាំថ្ងៃ ហើយ Kroma ប្រើ Google Translate ជំនួស និងប្រាប់អ្នក។ មើល [ការបកប្រែ](translation)។

## នាំចេញមិនបាន

កំណត់ហេតុពេញលេញត្រូវបានរក្សាទុកជា `last-export-error.log` ក្នុងថតការកំណត់របស់ Kroma។ [បើក issue](https://github.com/Heang-Dev/KROMA.STUDIO/issues) ហើយភ្ជាប់វា។

## បញ្ហាផ្សេងទៀត

[បើក issue នៅលើ GitHub](https://github.com/Heang-Dev/KROMA.STUDIO/issues) ដោយបញ្ជាក់កំណែ Kroma របស់អ្នក (Settings → About) និងអ្វីដែលបានកើតឡើង។
