បង្ហោះទៅ YouTube, Facebook និង TikTok ដោយចុចតែម្តង ជាមួយចំណងជើង អត្ថបទ និង hashtag ដែលសរសេរសម្រាប់វេទិកានីមួយៗ។

## ភ្ជាប់គណនីរបស់អ្នក (តែម្តង)

Kroma បង្ហោះតាមរយៈ **Upload-Post** ដែលវេទិកាទាំងនោះបានអនុម័តរួចហើយ ដូច្នេះការបង្ហោះរបស់អ្នកចេញជាសាធារណៈ។

1. បង្កើតគណនីឥតគិតថ្លៃនៅ [upload-post.com](https://app.upload-post.com/) ហើយបង្កើត API key។
2. បិទភ្ជាប់វាទៅក្នុង **Settings → Posting**។
3. ចុច **Connect** ហើយចូលគណនី YouTube, Facebook និង TikTok ក្នុងកម្មវិធីរុករករបស់អ្នក។
4. ជ្រើស Facebook Page របស់អ្នក (Facebook អនុញ្ញាតឱ្យកម្មវិធីបង្ហោះតែទៅ Page ប៉ុណ្ណោះ)។

## បង្ហោះវីដេអូ

1. នៅក្នុង **Post** ចុច **Write the posts**។ AI សរសេរចំណងជើង អត្ថបទ និង hashtag សម្រាប់វេទិកានីមួយៗ ហើយអ្នកអាចកែអ្វីក៏បាន។ ពួកវារក្សាទុកជាមួយគម្រោង។
2. ធីកវេទិកា។ ជ្រើសការមើលឃើញលើ YouTube និង TikTok **Post now** ឬ **To drafts**។
3. ចុច **Post**។ Kroma នាំចេញ (ឬប្រើវីដេអូដែលនាំចេញចុងក្រោយ បើគ្មានអ្វីផ្លាស់ប្តូរ) ផ្ទុកឡើងម្តង ហើយតាមដានវេទិកានីមួយៗរហូតដល់ចប់។

**Posted** រក្សាប្រវត្តិ ព្រមទាំងតំណទៅការបង្ហោះនីមួយៗ។ Facebook ទទួលបាន Reel សម្រាប់វីដេអូបញ្ឈរ មិនលើស ៩០ វិនាទី បើមិនដូច្នោះទេ ជាវីដេអូ Page។

## គម្រោង

YouTube និង Facebook ប្រើបានជាមួយគម្រោងឥតគិតថ្លៃរបស់ Upload-Post (១០ ការបង្ហោះក្នុងមួយខែ)។ TikTok ត្រូវការគម្រោង Basic របស់ពួកគេ។
