Kroma អាចបង្ហោះវីដេអូដែលធ្វើរួចរបស់អ្នក ទៅ YouTube, Facebook និង TikTok ដោយចុចតែម្តង។ AI សរសេរចំណងជើង អត្ថបទ និង hashtag សម្រាប់វេទិកានីមួយៗ ហើយអ្នកអាចកែវាមុនពេលបង្ហោះ។

សូមបង្ហោះតែវីដេអូដែលអ្នកមានសិទ្ធិប្រើប៉ុណ្ណោះ។ បើអ្នកបានបកប្រែវីដេអូរបស់អ្នកដទៃ សូមប្រាកដថាអ្នកមានការអនុញ្ញាតពីគេឱ្យចែករំលែកវា។

## របៀបដែលវាដំណើរការ

Kroma មិនបង្ហោះទៅវេទិកាដោយផ្ទាល់ទេ។ វាបង្ហោះតាមរយៈសេវាមួយឈ្មោះ **Upload-Post** (upload-post.com)។ YouTube, Facebook និង TikTok បានអនុម័ត Upload-Post រួចហើយ ដូច្នេះការបង្ហោះរបស់អ្នកចេញជាសាធារណៈ។

អ្នករៀបចំវាតែម្តង៖

1. បង្កើតគណនី Upload-Post និង API key មួយ។
2. បិទភ្ជាប់ key ទៅក្នុង Kroma។
3. ភ្ជាប់គណនី YouTube, Facebook និង TikTok របស់អ្នក។

បន្ទាប់មក ការបង្ហោះគ្រាន់តែចុចម្តងពីផ្ទាំង **Post**។

## គម្រោង និងដែនកំណត់

| វេទិកា | គម្រោង Upload-Post |
|---|---|
| YouTube | គម្រោងឥតគិតថ្លៃ |
| Facebook | គម្រោងឥតគិតថ្លៃ |
| TikTok | ត្រូវការគម្រោង **Basic** ដែលបង់ប្រាក់ |

គម្រោងឥតគិតថ្លៃ អនុញ្ញាត **១០ ការបង្ហោះក្នុងមួយខែ**។ ពេលប្រើអស់ អ្នកនឹងឃើញ "This month's Upload-Post uploads are used up (the free plan has 10). Upgrade the plan or wait for next month."

ទាំងនេះជាគម្រោងរបស់ Upload-Post មិនមែនរបស់ Kroma ទេ។ Kroma ខ្លួនឯងគឺឥតគិតថ្លៃ។

## រៀបចំការបង្ហោះ (តែម្តង)

### ១. បង្កើតគណនី និង API key

API key គឺជាពាក្យសម្ងាត់វែងមួយ ដែលអនុញ្ញាតឱ្យ Kroma ប្រើគណនី Upload-Post របស់អ្នក។

1. បើក **Settings** (⌘,) → **Posting**។ នៅក្រោម **Getting started** ចុច **Open** ដើម្បីទៅ upload-post.com ហើយចុះឈ្មោះដោយឥតគិតថ្លៃ។
2. ក្នុង Upload-Post ចូលទៅ **API Keys** ហើយបង្កើត key មួយ។ ចម្លងវា។
3. ត្រឡប់មក Kroma វិញ បិទភ្ជាប់វាទៅក្នុង **API key** ហើយរក្សាទុក។

ឥឡូវ ជួរ **Account** បង្ហាញអ៊ីមែល និងគម្រោងរបស់អ្នក ឧទាហរណ៍ "you@example.com · free plan" ជាមួយសញ្ញាធីកពណ៌បៃតង។ ចុច **Check** ដើម្បីពិនិត្យម្តងទៀត។ បើ key ខុស អ្នកនឹងឃើញ "Upload-Post refused the API key."

### ២. ភ្ជាប់គណនីរបស់អ្នក

1. នៅក្រោម **Your accounts** ចុច **Connect**។
2. ទំព័រ Upload-Post ដែលមានសុវត្ថិភាពមួយ បើកក្នុងកម្មវិធីរុករករបស់អ្នក។ ចូលគណនី YouTube, Facebook និង TikTok ហើយអនុញ្ញាតការចូលប្រើ។ (ទំព័រនេះប្រើបាន ៤៨ ម៉ោង។)
3. ត្រឡប់មក Kroma វិញ។ វាធ្វើបច្ចុប្បន្នភាពដោយខ្លួនឯង ពេលអ្នកត្រឡប់មក។

ឥឡូវ វេទិកានីមួយៗបង្ហាញឈ្មោះគណនីដែលបានភ្ជាប់ ឬ **Not connected**។ បើការចូលគណនីផុតកំណត់ វាបង្ហាញ "sign-in expired: press Connect"។ ចុច **Connect** ម្តងទៀត ដើម្បីដោះស្រាយ។

Upload-Post រក្សាគណនីរបស់អ្នកក្នុង **profile** មួយ។ បើអ្នកមិនទាន់មាន Kroma បង្កើតមួយឈ្មោះ "Kroma Studio" ឱ្យអ្នក។ បើគណនី Upload-Post របស់អ្នកមាន profile ច្រើនជាងមួយ ម៉ឺនុយ **Profile** អនុញ្ញាតឱ្យអ្នកជ្រើសមួយដែល Kroma បង្ហោះទៅ។

### ៣. ជ្រើស Facebook Page របស់អ្នក

Facebook អនុញ្ញាតឱ្យកម្មវិធីបង្ហោះតែទៅ **Page** ប៉ុណ្ណោះ មិនមែនទៅ profile ផ្ទាល់ខ្លួនទេ។ បន្ទាប់ពីភ្ជាប់ Facebook សូមជ្រើស Page របស់អ្នកក្នុងម៉ឺនុយ **Facebook Page**។ បើវាបង្ហាញ **No Pages found** សូមបង្កើត Page មួយនៅលើ Facebook ជាមុនសិន។

បើអ្នកមាន Page តែមួយ Kroma ប្រើវាដោយស្វ័យប្រវត្តិ។

## បង្ហោះវីដេអូ

បើកផ្ទាំង **Post** (ម៉ឺនុយខាងឆ្វេង)។ វាមានរហូតដល់បួនផ្នែក។

### 1 · Posts

ចុច **Write the posts**។ AI អានអក្សររត់ដែលបកប្រែរួចរបស់អ្នក ហើយសរសេរការបង្ហោះមួយសម្រាប់វេទិកានីមួយៗ ជាភាសានៃអក្សររត់៖

| វេទិកា | អ្វីដែល AI សរសេរ |
|---|---|
| **YouTube** | ចំណងជើងដែលមនុស្សអាចស្វែងរកឃើញ (ក្រោម ៩០ តួអក្សរ) និងការពិពណ៌នា ២–៣ កថាខណ្ឌខ្លីៗ |
| **Facebook** | ការបង្ហោះកក់ក្តៅ ដែលធ្វើឱ្យមនុស្សចង់ដឹង |
| **TikTok** | ឃ្លាទាក់ទាញខ្លីបំផុតមួយ |

ការបង្ហោះនីមួយៗក៏ទទួលបាន hashtag ៥–១០ ដែរ លាយភាសារបស់អ្នក និងភាសាអង់គ្លេស។ AI ត្រូវបានប្រាប់មិនឱ្យប្រឌិតការពិតដែលមិនមានក្នុងវីដេអូ។ វាក៏ប្រើឈ្មោះគម្រោង និងកំណត់ចំណាំបកប្រែរបស់អ្នកដែរ។

ការបង្ហោះនីមួយៗជាកាតមួយ ដែលមាន **ចំណងជើង** **អត្ថបទ** និង **hashtag**។ កែអ្វីក៏បាន៖

- វាយក្នុងប្រអប់ចំណងជើង និងអត្ថបទ។
- វាយ hashtag មាន ឬគ្មាន `#` ក៏បាន បំបែកដោយដកឃ្លា ឬក្បៀស ឧទាហរណ៍ `#food #fyp`។ ពួកវារក្សាទុក ពេលអ្នកចាកចេញពីប្រអប់ ឬចុច Enter។
- **Copy** ចម្លងការបង្ហោះទាំងមូល (ចំណងជើង អត្ថបទ និង hashtag) បើអ្នកចង់បិទភ្ជាប់វានៅកន្លែងផ្សេងដោយខ្លួនឯង។

ការបង្ហោះរបស់អ្នក រក្សាទុកជាមួយគម្រោង។ ចុច **Write them again** ដើម្បីបានថ្មី។

ការសរសេរការបង្ហោះត្រូវការ key AI៖ Gemini (ឥតគិតថ្លៃ) ឬ Claude។ Google Translate មិនអាចសរសេរការបង្ហោះបានទេ។ មើល [បញ្ចូល key របស់អ្នក](configuration)។ បើគ្មាន អ្នកនឹងឃើញ "Writing posts needs an AI: add a free Gemini key (or a Claude key) in Settings → Translation."

បើអ្នកចុចបង្ហោះ មុនពេលសរសេរការបង្ហោះ Kroma សរសេរវាជាមុនសិន។

### 2 · Post to

បើអ្នកមិនទាន់រៀបចំការបង្ហោះ ផ្នែកនេះបង្ហាញប៊ូតុង **Connect accounts** ដែលបើក **Settings → Posting**។

បើរៀបចំរួច៖

1. **ធីកវេទិកា។** គណនីដែលបានភ្ជាប់ ត្រូវបានធីករួចពីដំបូង។ វេទិកាដែលមិនបានភ្ជាប់ ជាពណ៌ប្រផេះ ជាមួយប៊ូតុង **Connect**។
2. **ការមើលឃើញលើ YouTube៖** **Public** (លំនាំដើម) **Unlisted** (មានតែអ្នកមានតំណប៉ុណ្ណោះអាចមើលឃើញ) ឬ **Private** (មានតែអ្នក)។
3. **TikTok៖** **Post now** បង្ហោះភ្លាម។ **To drafts** ផ្ញើវាទៅសេចក្តីព្រាង TikTok របស់អ្នក ដូច្នេះអ្នកអាចបន្ថែមតន្ត្រី ឬ effect ក្នុងកម្មវិធី TikTok រួចបង្ហោះដោយខ្លួនឯង។
4. **Video៖** បើអ្នកបាននាំចេញវីដេអូ ហើយគ្មានអ្វីផ្លាស់ប្តូរតាំងពីពេលនោះ Kroma ប្រើឯកសារនោះឡើងវិញ ("Uses your last export (nothing changed since).") ហើយបង្ហាញសញ្ញាធីកពណ៌បៃតង។ បើមិនដូច្នោះទេ ជ្រើសទំហំនាំចេញ៖ **Small**, **Standard** (លំនាំដើម) ឬ **High**។ មើល [នាំចេញ](export)។
5. ចុចប៊ូតុង។ វាដាក់ឈ្មោះវេទិកា ឧទាហរណ៍ **Post to YouTube, Facebook, TikTok**។

ប៊ូតុងនេះជាពណ៌ប្រផេះ ពេលបន្ទាត់ពេលវេលាទទេ ពេលគ្មានអក្សររត់ដែលបកប្រែ ឬពេលមិនបានធីកវេទិកាណាមួយ (ពេលនោះវាបង្ហាញ **Choose where to post**)។

### អ្វីកើតឡើងបន្ទាប់

1. Kroma នាំចេញវីដេអូ លើកលែងតែវាអាចប្រើការនាំចេញចុងក្រោយរបស់អ្នកឡើងវិញ។
2. វាផ្ទុកវីដេអូឡើង **តែម្តង** ទៅ Upload-Post ជាមួយចំណងជើង និងអត្ថបទផ្ទាល់របស់វេទិកានីមួយៗ។
3. វាតាមដានវេទិកានីមួយៗរហូតដល់រួចរាល់។ វឌ្ឍនភាពបង្ហាញ ឧទាហរណ៍ "Posting · 1/3 platforms done"។

វេទិកាអាចប្រើពេលយូរបន្តិច ដើម្បីដំណើរការវីដេអូ។ Kroma បន្តពិនិត្យរហូតដល់ ៣០ នាទី។ បើវេទិកាណាមួយនៅតែមិនទាន់រួច វាបង្ហាញ "Still processing on the platform. Check it there in a few minutes."

ពេលរួចរាល់ សារមួយបង្ហាញ "Posted to YouTube, Facebook" ឬ "Not posted to TikTok" ជាមួយមូលហេតុ។ បើអ្នកបានផ្ញើ TikTok ទៅសេចក្តីព្រាង វារំលឹកអ្នកឱ្យបើកកម្មវិធី TikTok ហើយបង្ហោះវាពីសេចក្តីព្រាង។

ការបង្ហោះនីមួយៗ ត្រូវបានផ្ញើជាមួយ key ពិសេសរបស់វា ដូច្នេះបើសំណើផ្ទុកឡើងដដែលទៅដល់ Upload-Post ពីរដង វាត្រូវបានបង្ហោះតែម្តងប៉ុណ្ណោះ។

### អ្វីទៅកន្លែងណា

- **YouTube៖** ចំណងជើងរបស់អ្នក (រហូតដល់ ១០០ តួអក្សរ) និងអត្ថបទ ដែលមាន hashtag បន្ថែមនៅខាងចុង (រហូតដល់ ៥០០០ តួអក្សរ)។ hashtag ក៏ត្រូវបានបន្ថែមជា tag របស់ YouTube ដែរ។
- **Facebook៖** **Reel** បើវីដេអូបញ្ឈរ (9:16) ហើយមិនលើស ៩០ វិនាទី។ បើមិនដូច្នោះទេ ជាវីដេអូធម្មតានៅលើ Page របស់អ្នក។ hashtag ត្រូវបានបន្ថែមនៅខាងចុងអត្ថបទ។
- **TikTok៖** ចំណងជើង និងអត្ថបទរួមគ្នា ជាមួយ hashtag នៅខាងចុង រហូតដល់ ២២០០ តួអក្សររបស់ TikTok។

អ្វីដែលវែងជាងវេទិកាអនុញ្ញាត ត្រូវបានកាត់ឱ្យខ្លី ហើយបញ្ចប់ដោយ "…"។

### Posted

បន្ទាប់ពីអ្នកបង្ហោះ ផ្នែក **Posted** រក្សាប្រវត្តិសម្រាប់គម្រោងនេះ ថ្មីបំផុតនៅខាងលើ។ ធាតុនីមួយៗបង្ហាញកាលបរិច្ឆេទ និងម៉ោង បន្ទាប់មកវេទិកានីមួយៗ៖

- សញ្ញាធីកពណ៌បៃតង ពេលបង្ហោះរួច ជាមួយប៊ូតុង **Open** ដែលបើកការបង្ហោះក្នុងកម្មវិធីរុករករបស់អ្នក
- សញ្ញាខ្វែងពណ៌ក្រហម ពេលបរាជ័យ ជាមួយមូលហេតុ
- រូបវិល ពេលនៅកំពុងដំណើរការ

ប្រវត្តិនេះរក្សាទុកជាមួយគម្រោង។

### Subtitle files

នៅខាងក្រោម **Subtitle files** រក្សាទុកអក្សររត់របស់អ្នកជាឯកសារ `.srt` សម្រាប់ផ្ទុកអក្សររត់ឡើង YouTube ឬទុកជាច្បាប់ចម្លង៖

- **Khmer .srt** (ឬឈ្មោះភាសារបស់អ្នក)៖ អក្សររត់ដែលបកប្រែ។
- **Original .srt**៖ អក្សររត់ដើម។
