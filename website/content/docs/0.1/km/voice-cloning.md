ចម្លងសំឡេងមួយ ដើម្បីប្រើវាសម្រាប់តួអង្គណាក៏បាន។

## ថតក្នុងកម្មវិធី

1. បើក **Voices** → **Clone voice** → **Record now**។
2. អានអត្ថបទនៅលើអេក្រង់ឱ្យឮ (ប្រហែល ១៥ វិនាទី) ក្នុងបន្ទប់ស្ងាត់ ដោយដាក់មីក្រូហ្វូនឆ្ងាយប្រហែលមួយចំអាមដៃ។
3. ស្តាប់ឡើងវិញ។ ចុច **Record again** បើវាមិនច្បាស់។
4. ដាក់ឈ្មោះ បញ្ជាក់ថាអ្នកមានសិទ្ធិប្រើសំឡេងនោះ ហើយចុច **Clone voice**។

ដោយសារអ្នកអានអត្ថបទដែលដឹងស្រាប់ ការចម្លងប្រើពេលតែប៉ុន្មានវិនាទីប៉ុណ្ណោះ។

## ប្រើឯកសារ

ជ្រើស **Use a file** ដើម្បីចម្លងពីការនិយាយច្បាស់ៗរបស់មនុស្សម្នាក់ ៥ ដល់ ២០ វិនាទី ដោយគ្មានតន្ត្រី។

## នាំចូលពី Khmer Voice Studio

**Voices → Import from KVS** ចម្លងសំឡេងពីផ្ទាំងគ្រប់គ្រង Khmer Voice Studio របស់អ្នក។ សំឡេងគំរូមកដោយខ្លួនឯង ចំណែកសំឡេងចម្លងត្រូវការការបញ្ជាក់របស់អ្នក។

## ការយល់ព្រម

ចម្លងតែ **សំឡេងរបស់អ្នកផ្ទាល់** ឬសំឡេងដែលអ្នកមានការអនុញ្ញាតពីម្ចាស់សំឡេងប៉ុណ្ណោះ។ កុំប្រើសំឡេងដើម្បីក្លែងខ្លួនជាអ្នកដទៃ រួមទាំងអ្នកចម្រៀង និងបុគ្គលល្បីៗ។
