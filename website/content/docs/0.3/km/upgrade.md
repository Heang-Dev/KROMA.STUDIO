របៀបផ្លាស់ពី 0.2 ទៅ 0.3 (ឬពី 0.1) អ្វីដែលផ្លាស់ប្តូរ អ្វីដែលនៅដដែល និងរបៀបត្រឡប់ទៅកំណែចាស់វិញ។

## ពី 0.2 ទៅ 0.3៖ មិនចាំបាច់ធ្វើអ្វីទេ

Kroma ធ្វើបច្ចុប្បន្នភាពទៅ 0.3 ដោយខ្លួនឯង ដូចការធ្វើបច្ចុប្បន្នភាពធម្មតា៖ ពេលកាតនៅខាងក្រោមស្តាំបង្ហាញ **Restart to update** សូមចុចវា។ គម្រោង ការកំណត់ គន្លឹះ សំឡេង រចនាប័ទ្ម និងសទ្ទានុក្រមរបស់អ្នក នៅដដែលទាំងអស់។

រឿងថ្មីតែមួយគឺភាសា៖ 0.3 អាចប្រើជាភាសាខ្មែរបាន។ វាចាប់ផ្តើមជា **Automatic** ដូច្នេះបើកុំព្យូទ័ររបស់អ្នកកំណត់ជាភាសាខ្មែរ Kroma បើកជាភាសាខ្មែរក្រោយការធ្វើបច្ចុប្បន្នភាព បើមិនដូច្នោះទេ វានៅជាភាសាអង់គ្លេស។ ប្តូរវាពេលណាក៏បានក្នុង **Settings → Appearance → Language**។ មើល [ភាសា](settings#ភាសា)។

## ពី 0.1 ទៅ 0.2៖ មិនចាំបាច់ធ្វើអ្វីទេ

បើអ្នកមាន 0.1.1 ឬថ្មីជាងនេះ Kroma ធ្វើបច្ចុប្បន្នភាពទៅ 0.2 ដោយខ្លួនឯង ដូចការធ្វើបច្ចុប្បន្នភាពធម្មតា៖

1. Kroma ពិនិត្យរកកំណែថ្មីពេលវាចាប់ផ្តើម និងរៀងរាល់ ៤ ម៉ោងម្តង។
2. វាទាញយក 0.2 នៅពីក្រោយ។ ប្រអប់មួយនៅខាងស្តាំខាងក្រោមបង្ហាញដំណើរការ។
3. ពេលប្រអប់នោះបង្ហាញ **Restart to update** ចុចវាពេលអ្នករួចរាល់។ Kroma បើកឡើងវិញជាមួយ 0.2 ហើយគម្រោងរបស់អ្នកបើកមកវិញ។

គ្មានអ្វីត្រូវបម្លែង ហើយគ្មានអ្វីត្រូវរៀបចំម្តងទៀតទេ។ គម្រោង ការកំណត់ key សំឡេង និងរឿងរបស់អ្នក នៅដដែលទាំងអស់។ បើ **Update automatically** បិទ ចុច **Download** លើប្រអប់ ឬ **Check now** ក្នុង **Settings → About**។ ព័ត៌មានលម្អិតសម្រាប់ប្រព័ន្ធនីមួយៗ មាននៅ [ការធ្វើបច្ចុប្បន្នភាព](updates)។

បើអ្នកនៅមាន **0.1.0** វាមិនអាចធ្វើបច្ចុប្បន្នភាពដោយខ្លួនឯងបានទេ៖ ទាញយក 0.2 ម្តងពី[ទំព័រទាញយក](/#download) ហើយដំឡើងវាពីលើកំណែចាស់ ដូចក្នុង [ការដំឡើង](installation)។ លើ Mac អូសវាទៅក្នុង **Applications** ហើយជ្រើសជំនួសកម្មវិធីចាស់។

## ពីររឿងដែលគួរពិនិត្យ

ទាំងនេះមិនមែនថ្មីក្នុង 0.2 ទេ ប៉ុន្តែអ្នកដែលមកពីកំណែ 0.1 ដំបូងៗ ពេលខ្លះរំលងវា៖

- **API key របស់អ្នក។** មុន 0.1.11 ការធ្វើបច្ចុប្បន្នភាពអាចធ្វើឱ្យ Kroma បាត់ key ដែលវាមិនអាចអានពី keychain របស់ Mac បាន។ បើប្រអប់ key ណាមួយក្នុង **Settings → Translation**, **Speech to Text** ឬ **Posting** នៅទទេ ឬប្រាប់ថាមាន key រក្សាទុក តែអានមិនបាន សូមបិទភ្ជាប់ key ម្តងទៀត។ ពេល Mac សួរ ជ្រើស **Always Allow**។ ចាប់ពី 0.1.11 key ត្រូវបានរក្សាទុកឆ្លងកាត់ការធ្វើបច្ចុប្បន្នភាព។
- **ការជូនដំណឹង។** 0.2 ប្រាប់អ្នកពេលការងារវែងៗរួចរាល់ ដោយការជូនដំណឹងរបស់ប្រព័ន្ធ និងសំឡេង។ បើអ្នកមិនឃើញ បើក **Settings → Notifications → Not seeing them?** ហើយអនុញ្ញាត Kroma Studio ក្នុងការកំណត់របស់ប្រព័ន្ធ។ មើល [ការជូនដំណឹង](notifications#មិនឃើញការជូនដំណឹង)។

## អ្វីដែលខុសគ្នាក្នុង 0.2

គ្មានអ្វីដែលអ្នកធ្លាប់ប្រើបាត់ទៅណាទេ។ មានរបស់ខ្លះប្តូរកន្លែង ឬប្តូរឈ្មោះ៖

| **Image / logo** ក្នុង **Objects** | **Image** |

| បង្ហោះឯកសារតែមួយទៅគ្រប់វេទិកា | វេទិកានីមួយៗទទួលទម្រង់ផ្ទាល់ខ្លួន៖ YouTube 16:9, Facebook និង TikTok 9:16 ជាលំនាំដើម។ មើល [ការបង្ហោះ](posting#ទម្រង់សម្រាប់វេទិកានីមួយៗ)។ |

## អ្វីដែលនៅដដែល

ការធ្វើបច្ចុប្បន្នភាពគ្រាន់តែជំនួសកម្មវិធីប៉ុណ្ណោះ។ អ្វីៗដែលអ្នកបានបង្កើតនៅដដែល ព្រោះវាស្ថិតនៅក្រៅកម្មវិធី ([ទីតាំងឯកសារ](projects-and-files#ទីតាំងឯកសារ))៖

| អ្វី | នៅដដែល? | ទីតាំង |
|---|---|---|
| គម្រោងរបស់អ្នក (ឯកសារ `.kroma`) | បាទ/ចាស ជាមួយរូបរាងដូចដើមទាំងស្រុង | កន្លែងណាដែលអ្នកបានរក្សាទុក |
| គម្រោងដែលអ្នកកំពុងបើក | បាទ/ចាស វាបើកមកវិញ | autosave ក្នុងថតការកំណត់របស់ Kroma |
| ការកំណត់ និង API key | បាទ/ចាស | `settings.json` ក្នុងថតការកំណត់របស់ Kroma |
| My styles | បាទ/ចាស | `my-styles.json` ក្នុងថតការកំណត់របស់ Kroma |
| ម៉ាស៊ីនសំឡេង | បាទ/ចាស | `voice-engine` ក្នុងថតការកំណត់របស់ Kroma |
| សំឡេងក្លូន និងគំរូសំឡេង | បាទ/ចាស | `voices` ក្នុងថតបណ្ណាល័យ Kroma Studio |
| រឿង ជួររង់ចាំទាញយក បញ្ជី batch | បាទ/ចាស | `stories`, `downloads`, `batch.json` ក្នុងថតបណ្ណាល័យ |
| បន្ទាត់សំឡេង ការទាញយក ការនាំចេញ | បាទ/ចាស | ថតបណ្ណាល័យ Kroma Studio |
| ទំហំផ្ទាំង ប្រវត្តិការជូនដំណឹង | បាទ/ចាស | កន្លែងផ្ទុកផ្ទាល់ខ្លួនរបស់ Kroma ក្នុងថតការកំណត់ |

គម្រោងដែលបង្កើតក្នុងកំណែ 0.1.x ណាមួយ បើកបានក្នុង 0.2។ គម្រោងដែលរក្សាទុកដោយ 0.2 អាចប្រើអ្វីដែល 0.1 មិនស្គាល់ ដូចជាអក្សររត់មានចលនា ឬគម្រប។

## ដំឡើងកំណែចាស់

បើកំណែថ្មីបង្កបញ្ហាដល់អ្នក អ្នកអាចត្រឡប់ក្រោយវិញបាន៖

1. បិទ **Settings → About → Update automatically** ដើម្បីកុំឱ្យ Kroma ធ្វើបច្ចុប្បន្នភាពម្តងទៀតភ្លាមៗ។
2. បើក [GitHub Releases](https://github.com/Heang-Dev/kroma/releases) ហើយរកកំណែដែលអ្នកចង់បាន។
3. នៅក្រោម **Assets** ទាញយកឯកសារសម្រាប់ប្រព័ន្ធរបស់អ្នក៖

| ប្រព័ន្ធ | ឯកសារ |
|---|---|
| macOS | `Kroma-Studio-<version>-arm64.dmg` |
| Windows | `Kroma-Studio-Setup-<version>.exe` |
| Linux | `Kroma-Studio-<version>-<arch>.AppImage` ឬកញ្ចប់ `.deb` |

4. ដំឡើងវាពីលើកំណែបច្ចុប្បន្ន ដូចក្នុង [ការដំឡើង](installation)។

គម្រោង និងការកំណត់របស់អ្នកនៅដដែល។ គម្រោងដែលរក្សាទុកដោយកំណែថ្មីជាង អាចប្រើអ្វីដែលកំណែចាស់មិនស្គាល់ (ឧទាហរណ៍ កំណែចាស់បង្ហាញអក្សររត់ដោយគ្មានចលនា) ដូច្នេះសូមរក្សាច្បាប់ចម្លងនៃអ្វីដែលសំខាន់ មុនពេលត្រឡប់ក្រោយ។ អានឯកសារណែនាំរបស់កំណែចាស់ ដោយប្រើម៉ឺនុយកំណែនៅខាងលើរបារចំហៀង ហើយមើលអ្វីដែលបានផ្លាស់ប្តូរក្នុង[កំណត់ចំណាំកំណែ](release-notes)។

សូម[រាយការណ៍បញ្ហា](troubleshooting#ការរាយការណ៍បញ្ហា)ផងដែរ ដើម្បីឱ្យវាអាចត្រូវបានជួសជុល។

## ផ្លាស់ទៅកុំព្យូទ័រថ្មី

1. ដំឡើង Kroma លើកុំព្យូទ័រថ្មី ([ការដំឡើង](installation)) ហើយលើ Mac ដំឡើងឧបករណ៍ម្តងទៀត (`brew install ffmpeg yt-dlp`)។
2. បន្ថែម API key របស់អ្នកម្តងទៀតក្នុង [Settings](settings)។ key ត្រូវបានអ៊ិនគ្រីបដោយ keychain របស់កុំព្យូទ័រចាស់ ដូច្នេះមិនអាចចម្លងទៅបានទេ។
3. ដំឡើងម៉ាស៊ីនសំឡេងម្តងទៀតក្នុង **Settings → Voice Engine** បើអ្នកប្រើវា។
4. ដើម្បីរក្សាសំឡេងក្លូន ចម្លងថត `voices` ពីថតបណ្ណាល័យ Kroma Studio ចាស់ ទៅក្នុងថតថ្មី នៅកន្លែងដដែល។ ចម្លង `stories` ផងដែរសម្រាប់រឿងរបស់អ្នក និង `my-styles.json` (ក្នុងថតការកំណត់) សម្រាប់រចនាប័ទ្មរបស់អ្នក។
5. ដើម្បីយកគម្រោងទៅ សូមធ្វើតាម [ផ្លាស់គម្រោងទៅកុំព្យូទ័រផ្សេង](projects-and-files#ផ្លាស់គម្រោងទៅកុំព្យូទ័រផ្សេង)។ ឯកសារគម្រោងគ្រាន់តែចង្អុលទៅវីដេអូ និងបន្ទាត់សំឡេងរបស់វា ដូច្នេះវាត្រូវតែចម្លងទៅកន្លែងដដែលផងដែរ។ សម្រាប់រឿងភាគ ចម្លងថតរបស់វាក្នុង `projects` ដែលមាន `kroma-glossary.json` របស់វា។

ការកំណត់ផ្សេងទៀតរបស់អ្នក (អ្នកបកប្រែ ថត រូបរាង ជាដើម) នៅក្នុង `settings.json`។ អ្នកអាចចម្លងឯកសារនោះទៅក្នុងថតការកំណត់របស់កុំព្យូទ័រថ្មី ពេល Kroma បិទ។ key នៅក្នុងវានឹងមិនដំណើរការទេ ដូច្នេះសូមបន្ថែមវាម្តងទៀត។
