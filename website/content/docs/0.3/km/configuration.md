Kroma ប្រើសេវា AI តាមអ៊ីនធឺណិត ដើម្បីស្តាប់វីដេអូ បកប្រែ និងសរសេរការបង្ហោះរបស់អ្នក។ អ្នកប្រើសេវាទាំងនោះជាមួយ **key ផ្ទាល់ខ្លួនរបស់អ្នក**។ API key គឺជាពាក្យសម្ងាត់វែងមួយដែលសេវាផ្តល់ឱ្យអ្នក ដើម្បីឱ្យវាដឹងថាសំណើមកពីគណនីរបស់អ្នក។ អ្នកមិនបង់អ្វីឱ្យ Kroma ទេ។ អ្នកបង់តែអ្វីដែលសេវានោះគិតប៉ុណ្ណោះ ហើយភាគច្រើនឥតគិតថ្លៃនៅពេលចាប់ផ្តើម។

## និយាយឱ្យខ្លី

សម្រាប់មនុស្សភាគច្រើន key ឥតគិតថ្លៃមួយគឺគ្រប់គ្រាន់ហើយ៖

1. យក key **Gemini** ឥតគិតថ្លៃនៅ [Google AI Studio](https://aistudio.google.com/apikey)។
2. នៅក្នុង Kroma បើក **Settings → Translation** ជ្រើស **Gemini** បិទភ្ជាប់ key ហើយចុច **Save**។

key មួយនោះប្រើបានសម្រាប់ការបកប្រែ ការបំប្លែងសំឡេងទៅជាអក្សរ ការស្វែងរកតួអង្គ ការរកឈ្មោះសម្រាប់សទ្ទានុក្រមរឿងភាគ និងការសរសេរការបង្ហោះលើបណ្តាញសង្គម។ អ្វីៗខាងក្រោមជាជម្រើសទាំងអស់។

## អ្វីកើតឡើងពេលបើក Kroma លើកដំបូង

ពេលអ្នកបើក Kroma ជាលើកដំបូងបង្អស់ វាបើក **Settings → Translation** ឱ្យអ្នក។ ក្រោយមក វាបើកនៅកន្លែងដែលអ្នកធ្វើការ។ បន្ថែម key មួយ ឬជ្រើស **Google Translate** (មិនត្រូវការ key) រួចចុច **Back to app** នៅខាងលើឆ្វេង ឬចុច `Esc` ដើម្បីទៅកម្មវិធីកែ។

អ្នកអាចត្រឡប់មកវិញពេលណាក៏បាន ដោយចុចប៊ូតុង **Settings** នៅខាងក្រោមរបារឆ្វេង ឬ `⌘ ,` លើ Mac (`Ctrl+,` លើ Windows និង Linux)។

| អ្នកបកប្រែ | កម្មវិធីសរសេរថា | ចំណាំ |

### Gemini

- **API key**៖ ចុច **Get a key** ដើម្បីបើក Google AI Studio។ មិនត្រូវការកាតទេ។
- **Model**៖ Kroma បង្ហាញម៉ូដែលដែល key របស់អ្នកអាចប្រើ ហើយកំណែថ្មីៗលេចឡើងដោយខ្លួនឯង។ លំនាំដើមគឺ `gemini-flash-latest` ដែល Google តែងតែចង្អុលទៅម៉ូដែល Flash បច្ចុប្បន្ន។ ម៉ូដែល Flash លឿន និងឥតគិតថ្លៃ។ Pro ល្អជាង ប៉ុន្តែកម្រិតឥតគិតថ្លៃតូចជាង។

កម្រិតឥតគិតថ្លៃកំណត់ចំនួនសំណើក្នុងមួយនាទី។ ពេលនោះ Kroma រង់ចាំ ហើយសាកម្តងទៀត។ បើ Gemini នៅតែរវល់ ឬកម្រិតឥតគិតថ្លៃប្រចាំថ្ងៃអស់ Kroma ប្តូរទៅម៉ូដែល Flash-Lite ដែលស្រាលជាង។ ឃ្លាដែល Gemini នៅតែបកប្រែមិនបាន ត្រូវបាន Google Translate បកប្រែ ហើយ Kroma ប្រាប់អ្នកថាមានប៉ុន្មានឃ្លា។

## សំឡេងទៅជាអក្សរ (Speech to Text)

ការបំប្លែងសំឡេងទៅជាអក្សរ ប្តូរការនិយាយក្នុងវីដេអូទៅជាឃ្លាដែលមានពេលវេលា។ Kroma ត្រូវការវាតែពេលវីដេអូមិនមានអក្សររត់ផ្ទាល់របស់គេហទំព័រប៉ុណ្ណោះ។ បើក **Settings → Speech to Text** ហើយជ្រើសសេវា៖

| សេវា | កម្មវិធីសរសេរថា | ចំណាំ |
|---|---|---|
| **Gemini** | Your Gemini key · accurate | លំនាំដើម។ ប្រើ key ពី Settings → Translation ដូច្នេះមិនចាំបាច់កំណត់អ្វីទៀតទេ។ ត្រឹមត្រូវណាស់ មានវណ្ណយុត្តិ ប៉ុន្តែចំណាយប្រហែលមួយនាទី សម្រាប់ការនិយាយរៀងរាល់ ២ នាទី។ |
| **Groq** | Free key · fastest | ដំណើរការ Whisper large-v3។ ភាពយន្តមួយរឿងក្នុងរយៈពេលប្រហែលមួយនាទី។ key ចាប់ផ្តើមដោយ `gsk_`។ |
| **OpenAI** | Paid · Whisper | ប្រើម៉ូដែល `whisper-1`។ key ចាប់ផ្តើមដោយ `sk-`។ |

សម្រាប់ភាពយន្តវែងៗ Groq លឿនជាង Gemini ច្រើន។

ជាមួយ Groq ឬ OpenAI ប្រអប់ **Advanced** បង្ហាញ **Endpoint** និង **Model**។ អ្នកអាចចង្អុល Kroma ទៅសេវាបំប្លែងសំឡេងណាក៏បាន ដែលត្រូវគ្នាជាមួយ OpenAI។ មនុស្សភាគច្រើនមិនដែលត្រូវប្តូរវាទេ។

## ម៉ាស៊ីនសំឡេង (ជម្រើស)

សំឡេងរហ័សរបស់ Microsoft មិនត្រូវការ key ទេ។ សម្រាប់សំឡេងចម្លង (បង្កើតពីការថតខ្លីមួយ) និងសំឡេងរចនា (អ្នកនិទានរឿង អ្នកអានព័ត៌មាន ជាដើម) Kroma ប្រើម៉ាស៊ីនសំឡេងផ្ទាល់ខ្លួនរបស់វា ដែលមានស្រាប់ក្នុងកម្មវិធី។ ក្នុង **Settings → Voice Engine** ចុច **Install voice engine** តែម្តង (ប្រហែល 2 GB) រួចចុច **Start engine**។ បើចង់ប្រើ GPU ឥតគិតថ្លៃរបស់ Google Colab ជំនួសវិញ ប្តូរ **Where it runs** ទៅ **Google Colab** ហើយបញ្ចូល **Engine address** និង **Token** របស់វា។ ជួរស្ថានភាពបង្ហាញថាម៉ាស៊ីនបើកឬអត់។ មើល [ម៉ាស៊ីនសំឡេង](voice-engine)។

## ការបង្ហោះ (ជម្រើស)

ដើម្បីបង្ហោះទៅ YouTube, Facebook និង TikTok ដោយចុចតែម្តង បន្ថែម key **Upload-Post** នៅក្នុង **Settings → Posting** រួចចុច **Connect** ដើម្បីចូលគណនីវេទិកានីមួយៗ។ YouTube និង Facebook ប្រើបានជាមួយគម្រោងឥតគិតថ្លៃរបស់ Upload-Post (១០ ការបង្ហោះក្នុងមួយខែ)។ TikTok ត្រូវការគម្រោង Basic របស់គេ។ មើល [ការបង្ហោះ](posting)។

មិនមែនជា key ទេ ប៉ុន្តែគួរកំណត់ម្តង៖

- **Settings → Downloads → Use my logins from**៖ គេហទំព័រខ្លះ ដូចជា Bilibili ផ្តល់ 1080p ឬចាក់វីដេអូខ្លះ តែពេលអ្នកចូលគណនីប៉ុណ្ណោះ។ ជ្រើសកម្មវិធីរុករកដែលអ្នកបានចូលគណនី៖ Chrome, Safari, Firefox, Edge ឬ Brave។ ប្រព័ន្ធរបស់អ្នកអាចសុំការអនុញ្ញាត។ Safari ត្រូវការ Full Disk Access ផងដែរ។ មើល [ការទាញយក](downloading)។
- **Settings → Folders**៖ កន្លែងដែលវីដេអូនាំចេញ និងវីដេអូទាញយកត្រូវទៅ។ លំនាំដើមគឺថត Movies (Mac) ឬ Videos (Windows, Linux) បន្ទាប់មក **Kroma Studio → Exports** និង **Kroma Studio → downloads**។ មើល [ការកំណត់](settings)។

## ការរក្សាទុក ការជំនួស និងការលុប key

ប្រអប់ key នីមួយៗដំណើរការដូចគ្នា៖

1. បិទភ្ជាប់ key ហើយចុច **Save**។ ស្លាក **Saved** ពណ៌បៃតងលេចឡើងក្បែរឈ្មោះ។
2. Kroma មិនបង្ហាញ key ដែលបានរក្សាទុកម្តងទៀតទេ សូម្បីតែឱ្យអ្នក។ ដើម្បីប្តូរ ចុច **Replace** បិទភ្ជាប់ key ថ្មី ហើយចុច **Save** (ឬ **Cancel**)។
3. ដើម្បីលុបវា ចុច **Remove**។

ការកំណត់រក្សាទុកភ្លាមៗពេលអ្នកប្តូរ។ គ្មានប៊ូតុង Save ដាច់ដោយឡែកសម្រាប់ទំព័រនោះទេ។

## របៀបដែល key របស់អ្នកត្រូវបានការពារ

- key ត្រូវបានទុកក្នុងឯកសារ `settings.json` របស់ Kroma ដោយអ៊ិនគ្រីបជាមួយ keychain នៃប្រព័ន្ធរបស់អ្នក (macOS Keychain, ការការពារទិន្នន័យរបស់ Windows ឬ keyring របស់ Linux)។ នៅលើកុំព្យូទ័រ Linux ដែលគ្មាន keyring វាត្រូវបានទុកដោយមិនអ៊ិនគ្រីប។
- key នីមួយៗត្រូវបានផ្ញើទៅតែសេវារបស់វាប៉ុណ្ណោះ។ key Gemini ទៅតែ Google, key Groq ទៅតែ Groq ជាដើម។
- Kroma គ្មានម៉ាស៊ីនមេផ្ទាល់ខ្លួនទេ។ គ្មានអ្វីឆ្លងកាត់ Kroma ទេ។
- key នៅតែរក្សាទុកឆ្លងកាត់ការធ្វើបច្ចុប្បន្នភាព។ បើកំណែថ្មីរបស់ Kroma មិនអាចអាន key ពី keychain របស់ Mac បាន key នោះនៅតែត្រូវបានរក្សាទុក ហើយ **Settings** ប្រាប់ថា *A key is saved, but this version of Kroma can't read it from the keychain*។ បិទភ្ជាប់វាម្តងទៀត ឬជ្រើស **Always Allow** ពេល Mac សួរ។
